# FIRST XI — 축구선수 커리어 시뮬레이터

## 개발 지침

**하드코딩 금지.** 모든 게임 수치, 명칭, 선택지, 콘텐츠, 규칙의 계수와 화면 문구는 `index.html` 내부의 `GAME DATABASE` (`<script id="game-db" type="application/json">`)에 저장한다. 엔진과 렌더링은 DB를 참조한다. 요소의 추가·수정·삭제는 DB 중심으로 처리하며, 로직에 별도 밸런스 값이나 클럽 목록을 넣지 않는다. 산술의 0/1, 해시·난수 알고리즘, HTML 구조와 CSS 레이아웃은 실행 구조이고 게임 밸런스 데이터와 구분한다.

게임 목표는 **데뷔 → 출전 경험 → 주전 확보 → 성장 → 상위 팀 이적 → 연봉·명성 축적**이다. 경기 화면 없이 상세 결과를 제공하고, 기록을 보존해 사용자가 경기력·시장·소속팀 정보를 직접 분석할 수 있도록 한다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행된다. 서버, 빌드, 외부 라이브러리 또는 네트워크 연결이 필요 없다. GitHub Pages에서도 같은 파일을 사용할 수 있다.

- 선수 이름, 국적, 나이, 신장, 체중, 주발, 주 포지션, 등번호, 희망 리그와 드림클럽을 설정한다.
- 스피드·슈팅·패스·피지컬·수비·드리블 슬라이더의 **단순 평균을 60–70**으로 맞춘다. 포지션 적합도는 별도의 가중 평균이다.
- 국내 하부리그, 유럽 변방 클럽, 명문 유스 중 첫 계약을 선택한다. 국내 경로는 선택한 국적의 리그를 사용한다.
- 대시보드에서 훈련을 선택하고 다음 경기를 진행한다. 즉시 결과 리포트로 이동한다.
- 일정·경기 결과, 선수 통계, 소속팀·리그, 이적시장, 프로필·계약을 탐색한다.

브라우저 저장소에 자동 저장한다. **내보내기 / 불러오기**는 DB와 커리어 전체를 함께 저장하므로 다른 브라우저에서도 이어갈 수 있다. 기존 제조업 시뮬레이터의 저장 데이터와는 별도 저장 키를 사용한다. 브라우저에서 파일 저장소 사용을 제한하거나 용량이 부족하면 안내가 표시되며, JSON 내보내기를 사용할 수 있다.

## 내부 DB 구조

| 테이블 | 관리 대상 |
| --- | --- |
| `meta` | 버전, 저장 키, 시작 날짜, 언어·통화, 저장 크기 제한 |
| `profile`, `attributes` | 생성 폼, 입력 범위, 주발, 초기 능력치 |
| `countries`, `leagues`, `clubs` | 국적별 데뷔 리그, 리그·클럽, 유스와 모팀 관계 |
| `positions` | 포지션별 적합도, 슈팅·패스·수비 참여 비중, 신체 기준 |
| `routes` | 첫 계약 경로, 경쟁 난이도, 감독 신뢰, 임금 계수 |
| `training`, `rules` | 성장, 회복, 부상, 출장 정지, 계약, 시장가치, 스카우팅 |
| `competitionRules` | 승점, 시즌 달력, 감독 역할 분류, 사기 영향 |
| `engine` | 선발 확률, 포메이션, 점유율, 패스, 슈팅, 경합, 평점 계수 |
| `names` | 생성 선수 이름 자료 |
| `ui` | 메뉴, 문구, 결과·통계 표시 항목 |
| `calibration` | 엔진 검증용 현실성 범위와 표본 수 |

파일의 JSON을 직접 편집하거나 게임의 **DB 편집**에서 변경·적용·내보내기할 수 있다. ID 중복, 클럽·리그 참조, 능력치 가중치, 확률, 필수 스키마를 검증한다. 기존 커리어가 사용하는 ID의 삭제·리그 이동은 방지한다. 새 리그에는 최소 두 클럽을 추가하고, 국내 데뷔 경로에 해당 국적의 적격 팀을 남겨야 한다. 경기 일정은 DB의 클럽 목록으로 자동 생성되며, 새 클럽·리그는 다음 시즌 일정부터 반영된다. 과거 경기 기록은 생성 시점의 스냅샷으로 유지한다.

## 경기·커리어 엔진

- 시드 기반 난수로 같은 DB·경기 ID·커리어 상태는 같은 결과를 만든다.
- 출전은 포지션 경쟁자의 적합도, 감독 신뢰, 최근 평점, 컨디션, 사기, 첫 계약 경로로 결정한다. 선발·교체·미출전을 구분하고 부상·출장 정지를 반영한다.
- 분 단위로 점유, 패스, 롱패스, 크로스, 드리블, 경합, 공중볼, 태클, 가로채기, 클리어링, 반칙·카드와 슈팅 이벤트를 산출한다.
- 슛 위치·유형별 xG를 누적하고 슈팅 능력, 상대 골키퍼, 주발, 신체, 컨디션을 추가 반영해 득점 여부를 결정한다. 유효슈팅은 득점 또는 선방으로 연결된다.
- 기회 창출 선수에게 키패스와 xA를 부여하고 실제 득점 시 도움을 기록한다. 자신의 슈팅에 자신의 도움이 붙지 않는다. 페널티킥에는 도움이 없다.
- 개인 데이터는 팀 데이터의 일부다. 출전 선수의 득점·패스·태클 등 합계와 팀 기록이 일치한다. 미출전은 평균 평점과 90분당 계산에서 제외한다.
- 해당 라운드의 모든 샘플 리그 경기를 진행하고 승점·득실·리그 순위를 갱신한다.
- 훈련·출전·나이로 성장하며, 컨디션과 부상 위험을 관리한다. 유스 실적이 기준을 충족하면 모팀으로 콜업할 수 있다.
- 출전 실적, 평균 평점, 포지션 적합도, 명성에 따라 상위 클럽의 계약 제안을 생성한다. 이적 기간과 제안 만료를 적용하고 재계약·다음 시즌을 지원한다.
- 시즌 달력은 연 단위다. 축약 리그의 시즌 종료 후 휴식 기간을 건너뛰며 해당 기간의 급여도 지급한다.

## 초기 버전의 범위

현재 8개 국적, 13개 리그, 78개 클럽의 **축약 샘플 DB**다. 각 리그는 6팀 홈·원정 10경기 시즌이며, 명문 유스는 개발 리그로 묶여 있다. 실제 최신 리그 구성, 로스터, 계약, 이적 규정이나 실측 통계를 재현한 데이터가 아니다. 클럽 능력·연봉·시장가치는 게임용 추정치이고 선수단은 생성한다.

현재 엔진은 통계 이벤트를 생성하는 초기 모델이다. 공간 좌표·전술 전개 전체, 오프사이드·VAR·교체 전술, 에이전트 협상, 국가대표·컵 대회, 실제 리그의 승강제는 후속 확장 범위다. 이 버전에서는 계약 제안과 유스 콜업으로 상위 팀에 진출한다. 부상은 경기 후 판정하며 다음 경기의 출전 가능 여부에 반영한다. 현실성은 DB 계수와 대량 표본 검증을 통해 보정하며 실제 축구와의 완전한 일치를 주장하지 않는다.

## 검증

Node.js로 실행한다. 별도 패키지는 필요 없다.

```sh
node tests/engine.test.cjs
```

DB 기반 대량 표본 보정, 기록 합계·경합·슈팅 일관성, 난수 재현성, 모든 포지션의 출전, 세 시작 경로, 부상·출장 정지, 저장 왕복, 계약·이적·콜업 및 시즌 전환을 검증한다.
