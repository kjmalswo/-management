# FIRST XI — 축구선수 커리어 시뮬레이터 v11.0

## 개발 지침

**하드코딩 금지.** 게임 수치·요소·선택지·규칙 계수·문구는 단일 `index.html`의 `game-db` JSON에서 관리합니다. 로직은 DB 참조와 계산을 담당합니다. 산술 0/1, 난수·해시 알고리즘, HTML/CSS 구조는 실행 구조입니다.

목표: 데뷔 → 출전 경험 → 주전 확보 → 성장 → 상위 팀 → 연봉·명성. 선발 전술판·라커룸 지시·텍스트 중계를 거쳐 상세 기록과 누적 통계를 제공합니다.

## 실행과 저장

`index.html`을 브라우저에서 열면 실행됩니다. 외부 라이브러리·서버·빌드가 필요 없습니다. 자동 저장과 JSON 내보내기/불러오기를 제공합니다. 기존 저장 키를 유지하고 schema 1·2·3·4·5·6·7·8·9 저장은 schema 10로 확장합니다. 기존 경기 기록은 보존되며 과거 경기의 새 심리 분석·반응은 소급 생성하지 않습니다. 과거 NPC 성장 이력은 복원할 수 없어 업데이트 시점부터 생성 세계가 시작됩니다.

IndexedDB 자동 저장과 압축한 로컬 보관본을 사용합니다. 자동 저장을 사용할 수 없으면 JSON으로 내보내기할 수 있습니다. 현재 시즌의 세계 결과는 요약으로 저장하고 개인 경기 보고서는 전체 기록을 유지합니다. 세계 연감은 최근 40시즌, 세계 이벤트는 최근 1,200개, 전체 리그 결과 아카이브는 최근 18시즌을 유지합니다.

## 선수 생성과 DNA

- 프로필, 신체, 주발, 희망 리그·팀을 지정합니다. 주·부·가능 포지션은 다른 칸에서 이미 선택한 값을 고르면 기존 포지션과 맞교환합니다. 초기 6능력치 평균은 최대 70이며, 420점 예산에서 추가 가능한 점수를 실시간 표시하고 예산을 넘기는 슬라이더 증가를 제한합니다. 60 미만의 평균도 허용합니다.
- 운동 재능, 잠재력, 축구 지능, 야망, 프로의식, 멘탈, 부상 취약성, 압박 대처, 향수병, 언어능력, 적응력, 침착성, 판단력을 슬라이더로 설정합니다.
- 성실한 조직형, 자유분방한 스타형, 승부욕 강한 야심가, 차분한 내향형은 장단점이 있습니다. 자유형은 규율·신뢰에 부담을 주지만 창의적 행동·스타성과 압박 해방에 이점이 있고, 기존 클럽 제안의 관심과 임금에도 스타성이 작용합니다. 스폰서 계약은 구현하지 않습니다.
- 꾸준함·빠른 습득·대기만성·노련함·회복 탄력성의 선천적 특성을 선택합니다. 성장 유형을 직접 고르지 않으며 특성별 경향과 선수 DNA를 가중해 성장 경향을 결정합니다. 개인별 성장 나이 편차·환경·확률적 도약과 정체가 실제 경로를 바꿉니다.
- 국내 하부리그 / 유럽 변방 / 명문 유스의 첫 계약을 선택합니다.

## 경기와 전술

분 단위 경기 이벤트는 조건부 확률로 처리합니다. 시드 난수는 같은 상태에서 재현 가능한 사건 판정에 사용합니다. 평점이나 득점을 독립적인 무작위 값으로 만들지 않습니다.

행동별 유효 능력 = 기본 능력 × 해당 행동의 침착성·판단·지능 등 가중 곱 × 경기 중 피로 × 경기 중요도/압박 대처 × 멘탈·사기 × 해외 적응 × 실제 출전 포지션 숙련 × 성격·전술·언어 효과입니다. 패스, 크로스, 슈팅·마무리, 드리블, 스프린트, 경합, 수비 행동은 각각 다른 특성 비중을 사용합니다. 경기 상황의 기회 종류/xG, 상대 골키퍼, 주발·신체도 반영합니다. 경기 리포트의 유효 능력 표는 경기 종료 시점의 조건을 보여주며 각 이벤트는 발생 시점 피로를 적용합니다.

감독마다 4-3-3 / 4-2-3-1 / 4-4-2 / 3-5-2 역할, 압박, 전개 속도, 창의성·규율 기대가 다릅니다. 주 포지션이 없는 경우 부·가능 포지션 또는 낯선 포지션으로 배치됩니다. 주·부·가능 숙련 배율은 DB에서 관리합니다. 낮은 숙련도는 선발 확률과 행동 실행 모두에 작용합니다. 감독 교체는 선수 평가와 신뢰를 다시 설정합니다.

개인·팀의 슈팅, xG/xA, 득점·도움, 패스, 경합, 태클·차단, 선방·실점, 거리·스프린트, 카드와 출전 시간을 기록합니다. 팬·언론 반응은 미출전, 퇴장, 큰 기회 실패, 골키퍼 기록, 활약·부진과 팀 결과에 맞춰 생성하며 사기·명성에도 제한적으로 반영합니다.

## 성장과 부상

타고난 능력별 상한과 현재 실현 가능한 상한을 분리합니다. 최근 출전 경험, 훈련 습관·프로의식·야망, 코칭, 클럽 환경, 사기, 부상 누적이 실현 상한을 움직입니다. 상한 하락만으로 현재 스탯을 바로 깎지는 않습니다. 출전 부족·정체·부상으로 성장 효율이 떨어지고 환경 개선으로 회복할 수 있습니다. 상한 가까이서는 성장 속도가 줄어듭니다.

나이별 성장 곡선, 도약·정체, 신체와 기술의 서로 다른 노화, 지능·판단·침착·멘탈의 출전 경험 학습을 적용합니다. 부상 취약성·피로·훈련 부하·회복 습관이 부상 확률에 작용합니다. 근육·인대·중증 무릎 부상의 회복 기간과 영구 손실이 다릅니다. 큰 부상 이후 연결형/위치선정형으로 성장 비중이 바뀔 수 있습니다. 시즌 사이 휴식 기간에도 축약된 훈련·회복을 처리합니다.

## 자율 세계와 DB

8국적, 19개 축약 리그, 129클럽의 샘플 세계입니다. 유스 리그 15팀, 나머지 리그별 6–9팀의 홈·원정 축약 시즌입니다. 팀 수에 따라 경기·라운드 수가 다르고 짧은 리그가 끝난 뒤에는 전체 세계 일정 종료까지 훈련·회복을 이어갑니다. 실측 최신 선수단이나 실제 계약 자료를 사용하지 않습니다.

- 생성 선수는 고유 ID와 나이·성격·포텐·능력·출전·부상 이력을 유지합니다. 출전 선수와 벤치의 경험 차이, 코칭과 습관에 따라 NPC도 성장하며 스타는 노화·은퇴합니다.
- 새 유망주, NPC 이적, 감독 교체, 경기 수입/임금과 시즌 재정 변동, 성장환경 변화, 전술 트렌드가 발생합니다.
- DB에 정의된 8개 국내 1·2부 쌍은 1팀씩 승격·강등하고 다음 시즌 일정·리그 급여·경쟁 상대가 바뀝니다. 포르투갈·이탈리아·유스 리그는 현재 승강 연결이 없습니다.
- 성장·선수 DNA 탭에서 상한과 성장 조건을, 세계 탭에서 유망주·스타·은퇴 선수 검색, 클럽 재정·감독, 소식과 연감을 확인합니다.

주요 DB: `traits`, `personalities`, `growthTypes`, `tactics`, `dynamics`, `worldConfig`, `media`, 기존 `profile/positions/attributes/countries/leagues/clubs/routes/training/rules/engine/ui`. 런타임 세계는 저장의 `state.world`, 개인 발달은 `player.development`에 저장됩니다. DB 편집은 스키마·ID·참조와 현재 저장의 호환성을 확인하고 원자적으로 적용합니다. 새 클럽·리그는 세계에 추가하며 일정은 다음 시즌부터 반영합니다.

## 범위와 다음 업데이트

스폰서·광고 계약은 다음 업데이트입니다. 상세 이적·재계약 협상과 메시지함은 v5에 추가했습니다. 경기 밖 이적·계약·감독·재정·승강·신인·은퇴·출전 부족·훈련 이슈의 언론/SNS 반응은 v4에 추가했습니다. 계약 제안은 즉시 수락 대신 구단·개인 조건·에이전트·메디컬 협상을 거쳐 최종 서명합니다. 공간 좌표, 실제 전술 전개 전체, VAR/오프사이드, 국가대표·컵대회, 현실의 복잡한 승강/재정 규정은 아직 포함하지 않습니다. 부상은 경기 후 판정입니다. 축약 이벤트 모델이며 실제 축구를 완전히 재현한다고 주장하지 않습니다.

v10은 불러오기 회귀 테스트와 PC·모바일 브라우저의 실제 파일 내보내기/불러오기·새로고침 복원 테스트를 실행했습니다. 기존 `tests/engine.test.cjs`는 중단 요청 확인 시 이미 종료되어 있었으며, 현재 기능/API와 맞지 않는 과거 기대값 4개가 실패했습니다. 사용자 요청에 따라 추가 엔진 검사는 실행하지 않습니다. 이번 수정의 불러오기 회귀 테스트와 PC·모바일 브라우저 검증은 통과했습니다. 새 저장 검증은 `tests/save-import.test.cjs`, 브라우저 확인은 `tests/browser-save-import.cjs`에 기록합니다.


## v11 팀 후보 다양화 · 협상 동기화 · 일정과 중계

시작 후보는 새 커리어마다 다시 선정합니다. 국내 경로의 후보 범위를 넓히고 유럽 경로는 포르투갈·잉글랜드·스페인·독일·프랑스의 하부 리그를 포함합니다. 명문 유스 6팀을 추가했습니다. 드림클럽과 희망 리그는 후보 선정 가중치로 반영하며 맨체스터 시티의 최하 잠금과 유스 제외는 유지합니다. 이적 제의는 선수의 실력·잠재력·구단 재정·전술 적합도를 반영하되 최근 제의 구단과 이미 제의한 리그의 가중치를 낮춰 후보를 다양화합니다.

에이전트의 구단 접촉은 3–6일 후, 조건 협상은 3–7일 후 회신합니다. 기다리는 동안 같은 접촉이나 협상안을 중복 제출할 수 없습니다. 메시지함과 이적 화면은 같은 협상 상태를 표시하며 철회·실패·서명된 협상과 과거 메시지에서 새 요청이 반복되지 않습니다. 오래된 중복 메시지와 회신 일정도 정리하며 최종 서명 때 같은 답변을 다시 발송하지 않습니다. 관련 후보·회신 규칙은 HTML DB의 startingRouteRules와 marketFlow에서 관리합니다.

일반 일정 진행은 0.5초의 짧은 전환 화면 뒤 처리합니다. 소속팀의 실제 미진행 경기가 해당 날짜에 있을 때만 경기 준비 → 선발 명단 → 라커룸 → 중계로 이동합니다. 다른 리그만 경기하는 날이나 자유계약 상태에서 개인 경기 준비 화면이 나타나지 않습니다. 전환 시간은 progressRules.delayMs에서 관리합니다.

텍스트 중계 슬라이더는 0.5배(2초), 1배(1초), 2배(0.5초)를 지원하며 기본은 1배입니다. 일시정지 중에도 변경할 수 있고 재생 중 변경하면 타이머를 새 간격으로 교체합니다. 같은 브라우저에서는 새로고침 후 선택을 유지합니다. 설정은 matchBroadcast.eventIntervalMs/speedOptions와 settings.defaults.broadcastSpeed에 있습니다. 기존 저장은 schema 10으로 확장하며 경기 기록·중계 단계·커서를 보존합니다.

플레이어와 다른 선수의 DNA 특성 수치는 소수점을 버려 정수로 표시합니다(61.9 → 61). 내부 계산과 저장된 원래 수치는 유지합니다.

검증: PC Chrome과 Pixel 7 모바일 에뮬레이션에서 일반 일정/개인 경기 준비 구분, 0.5초 전환, 중계 속도·일시정지·설정 복원, DNA 정수 표시를 확인했습니다. 시작 후보는 30개 시드에서 국내 6팀·유럽 5리그 17팀·유스 12팀이 선정되었습니다. 별도 적격 선수의 제의 6회에서는 18리그 34팀을 확인했습니다. 구단 접촉과 협상 회신 지연, 중복 제출 방지, 메시지/회신 일정 정리, 서명 시 답변 중복 방지도 확인했습니다. 저장된 경기 기록과 UI용 일정 대역을 사용했으며 경기 시뮬레이션이나 엔진 테스트는 실행하지 않았습니다. 브라우저 스크립트 오류는 없었습니다.
