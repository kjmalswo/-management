# FIRST XI — 축구선수 커리어 시뮬레이터 v17.1.0

## 개발 지침

**하드코딩 금지.** 게임 수치·요소·선택지·규칙 계수·문구는 단일 `index.html`의 `game-db` JSON에서 관리합니다. 로직은 DB 참조와 계산을 담당합니다. 산술 0/1, 난수·해시 알고리즘, HTML/CSS 구조는 실행 구조입니다.

목표는 데뷔 → 출전 경험 → 주전 확보 → 성장 → 상위 팀 → 연봉·명성입니다. 경기 흐름은 선발 전술판 → 라커룸 → 텍스트 중계 → 상세 결과입니다.

## 실행과 저장

`index.html`을 브라우저에서 열면 실행됩니다. 외부 라이브러리·서버·빌드가 필요 없습니다. IndexedDB에 현재 자동저장과 직전 저장을 같은 트랜잭션으로 보관하고, 최신 저장을 복원하지 못하면 이전 저장도 검사합니다. 압축한 로컬 보관본은 브라우저 용량 안에 들어갈 때 보조로 저장합니다. 확장된 전체 커리어는 로컬 보관 한도를 넘을 수 있으므로 IndexedDB와 JSON 내보내기/불러오기를 사용합니다. 자동 저장이 불가능하면 JSON 내보내기를 사용할 수 있습니다. 계정 클라우드 동기화는 없습니다.

저장 스키마는 13입니다. 이전 schema 1–12의 선수·계약·능력치·개인 경기 기록·중계 상태를 보존하면서 새 DB로 확장합니다. v12/schema 11 및 v13/schema 12 저장은 현재 일정과 경기 기록을 그대로 유지합니다. 더 이전 저장은 지원 리그의 구단 소속을 새 시즌 명단에 맞추고 미래 일정을 다시 만듭니다. 이미 끝난 경기는 결과·날짜를 유지하며 새 리그 구성과 맞지 않는 경기는 과거 경기로 보관합니다. 지나간 날짜에 새 경기를 추가하지 않습니다. 현재 소속 구단이 지원 명단에서 제외된 경우 `seasonCatalog.clubMigrations`의 대응 구단으로 옮기고 메시지함에 알립니다. 사용자 추가 리그·구단의 ID도 보존합니다.

현재 시즌의 세계 결과는 요약으로 저장하고 개인 경기 보고서는 전체 기록을 유지합니다. 세계 연감은 최근 40시즌, 세계 이벤트는 최근 1,200개, 전체 리그 결과 아카이브는 최근 18시즌을 유지합니다. JSON 불러오기 제한은 128MiB입니다. 잘못된 파일은 검증 후 거부하고 현재 커리어를 변경하지 않습니다. 브라우저 데이터 삭제·저장 제한 설정까지 보존을 보장하지는 않습니다.

웹 실행에서는 시작 시, 다시 화면으로 돌아올 때, 2분 간격으로 같은 주소의 배포 버전을 캐시 없이 확인합니다. 더 높은 버전을 발견하면 화면 하단에 **새 버전이 출시되었습니다. 업데이트해주세요.** 안내와 업데이트 버튼을 표시합니다. 버튼을 누르면 진행 중인 경기·플레이오프·선택을 저장하고 로딩을 표시한 뒤 새 페이지를 불러옵니다. 저장 실패 시 현재 화면을 유지하고 재시도를 안내합니다. 오프라인 파일 실행에서는 버전을 확인하지 않으며 네트워크 오류도 게임 진행을 막지 않습니다. 이 기능이 없던 기존 화면은 v16을 한 번 새로고침한 다음 배포부터 알림을 받습니다.

## 화면과 중계

프로필·성격 선택 화면에서도 상단 설정 버튼으로 화면 배치, 인터페이스 크기, 금액 단위를 변경할 수 있습니다. 돌아가기·설정 복원 후에도 작성 중인 프로필과 선택 단계를 유지합니다. 인터페이스 크기는 80–200%이며 자동/PC 화면 배치를 지원합니다.

텍스트 중계는 기존 중계창과 버튼을 유지하면서 새 이벤트만 추가합니다. 하단을 보고 있으면 새 내용을 즉시 따라가고, 위로 스크롤해 이전 내용을 읽으면 읽는 위치를 유지합니다. 일시정지·이어보기·경기 종료에서도 중계창과 페이지 스크롤·버튼 포커스를 유지합니다. 종료 시 버튼을 비활성화하여 화면 높이가 갑자기 줄지 않게 합니다.

중계 속도는 0.5배(2초), 1배(1초), 2배(0.5초)입니다. 일시정지 중에도 변경할 수 있고 새로고침 후 선택을 복원합니다. 창이 숨겨지면 중계를 멈춥니다. 경기 준비 때 결과를 한 번 계산하므로 중계 재개·스킵은 기록을 중복 누적하지 않습니다.

버튼은 호버·누름·키보드 포커스를 구분하고, 탭과 선택 상태는 색으로 표시합니다. 주요 버튼에 마우스를 두거나 키보드로 포커스하면 기능 설명이 나타납니다. 점선 밑줄이 있는 구단·리그·선수·감독 이름을 누르면 상세 정보 팝업을 볼 수 있습니다. 구단 팝업에는 현재 선수단 평균·구단 환경·감독·선수 명단이 있고, 리그 순위·득점·도움 기록이나 선수단 검색으로 이동할 수 있습니다. 연속해서 연 정보는 팝업의 이전 정보 버튼으로 돌아가며, 닫기/Escape 후 원래 버튼으로 포커스가 돌아갑니다.

xG·xA·오버롤·컨디션 등 주요 수치의 점선 설명 버튼은 호버 또는 클릭으로 의미를 안내합니다. 모바일은 탭으로 정보 팝업을 엽니다. 툴팁은 화면 가장자리와 200% 배율에 맞춰 배치하며, 스크롤·화면 전환·Escape 시 닫힙니다. 시스템의 모션 줄이기 설정에서는 새 누름·팝업 애니메이션을 생략합니다. 설명 데이터는 `ui.interactions`에 있고 이전 자동저장에 추가합니다. 경기 엔진과 저장 스키마는 변경하지 않습니다.

## 구단 투톤 색상

DB의 1,091개 구단(성인 551개, 유스 540개, 과거 저장용 구단 포함)에 대표 주색 `color`와 보조색 `secondaryColor`를 지정합니다. 유스는 모구단의 두 색을 사용합니다. 구단 마크·선수 유니폼·양 팀 선발 전술판은 두 색을 반반 배치하며, 구단 약칭·선수 이름·등번호는 주색 배경 위에 대비가 높은 글자색으로 표시합니다. 외부 이미지나 네트워크 없이 동작합니다.

공식 구단·리그 소개와 공개 유니폼 자료를 참고한 화면용 대표색 근사치입니다. 공식 로고나 특정 시즌 홈 유니폼의 무늬·Pantone 값을 그대로 복제하지 않습니다. 세 가지 이상의 상징색을 쓰는 팀도 화면에서는 대표 두 색을 표시합니다. 참고 자료: [K리그 김해 유니폼](https://www.kleague.com/news_view.do?orderBy=seq&page=1&seq=94424&viewOption=album), [J리그 구단 프로필](https://www.jleague.jp/club/fujieda/profile/), [프리미어리그 구단](https://www.premierleague.com/en/clubs), [라리가 구단](https://www.laliga.com/laliga-easports/clubes), [분데스리가 구단](https://www.bundesliga.com/de/bundesliga/clubs), [세리에 A 구단](https://www.legaseriea.it/team), [MLS 구단](https://www.mlssoccer.com/clubs/), [USL 공개 유니폼](https://www.uslchampionship.com/news_article/show/1357111), [브루클린 구단 색 설명](https://www.brooklynfootballclub.com/2025/07/31/behind-the-scenes-at-maimonides-park-a-brooklyn-fc-matchday-experience-brooklyn-fc/), [티옹빌 서포터 소개](https://www.ustl.fr/supporters).

이전 저장의 기본 색은 불러올 때 새 배색으로 교체합니다. 사용자가 수정한 색과 이미 지정한 보조색, 사용자 추가 구단은 유지합니다. 주색만 지정한 사용자 구단에는 보조색을 채워 두 색으로 표시합니다. 경기 결과·일정·계약·선수 능력치는 바꾸지 않습니다. 마이그레이션 기준 색은 `teamColorRules`, 글자 대비 계산은 `uniformRules.contrastRules`에서 관리합니다.

선택지의 체력·신뢰·사기·적응·에이전트 신뢰 긍정 보상을 기존의 두 배로 높입니다. 집중 효과는 21일 동안 해당 능력의 경기 실행력 1.12배로 적용하며 즉시 능력치를 올리지 않습니다. 훈련 성장에는 아래의 주간·시즌 예산을 적용합니다. 비용인 체력·신뢰 감소는 그대로 적용하고 각 선택지에 실제 보상·비용을 표시합니다.

## 선수 생성과 DNA

- 프로필, 신체, 주발, 주·부·가능 포지션, 희망 리그·드림클럽을 지정합니다. 이미 다른 칸에서 선택한 포지션은 맞교환합니다. 초기 6능력치 평균은 최대 70이며 420점 예산을 표시합니다.
- 운동 재능·잠재력·축구 지능·야망·프로의식·멘탈·부상 취약성·압박 대처·향수병·언어능력·적응력·침착성·판단력을 설정합니다.
- 성실한 조직형, 자유분방한 스타형, 승부욕 강한 야심가, 차분한 내향형은 각각 다른 성격 효과를 갖습니다.
- 꾸준함·빠른 습득·대기만성·노련함·회복 탄력성의 선천적 특성과 DNA로 성장 경향을 결정합니다. 나이·환경·도약·정체가 실제 경로를 바꿉니다.
- 국내 하부리그 / 유럽 변방 / 명문 유스의 첫 계약 후보를 매번 새로 선정합니다. 실제 생성 선수단 평균 오버롤과 선수 평균의 차이를 중심으로 후보를 가중하고 희망 리그와 드림클럽도 반영합니다. 명문 유스 경로는 유스 선수단 수준으로 비교합니다.

## 필수 응답과 영입 제안

유효한 미응답 오퍼, 플레이어 답변/서명을 기다리는 협상, 현재 감독의 계획, 재계약 의사 확인이 있으면 상단 일정 버튼을 **응답하기**로 바꿉니다. 누르면 메시지함의 답변 필요 필터에서 해당 메시지를 바로 엽니다. 읽음 표시는 응답을 대신하지 않습니다. 오퍼는 협상·거절·나중에 검토로 처리할 수 있고 보류한 오퍼는 원래 기한까지 시장에 남습니다. 조건 합의 후 메디컬만 보류된 협상은 일정 진행을 막지 않습니다. 회복 중 3일 간격(남은 기한이 짧으면 기한 당일)으로 자동 재검사하며 협상 횟수를 소모하지 않습니다. 통과하면 서명 응답을 요청하고, 계약 조건에도 이견이 있으면 기존처럼 조건 응답이 필요합니다. 기한까지 통과하지 못하면 협상이 종료됩니다. 기존 저장의 멈춘 메디컬 보류도 불러올 때 재검사를 예약합니다. 협상 회신 대기 중에는 일정을 진행하며 새 답변/서명이 필요하면 다시 응답 버튼을 표시합니다. 만료·철회·서명·이적 예약 상태와 과거 감독의 계획은 진행을 막지 않습니다.

계약 만료 90일 전부터 재계약 의사를 한 번 묻습니다. 협상을 시작하거나 재계약하지 않기를 선택합니다. 자동 재계약은 하지 않습니다. 이 게이트는 게임 화면의 일정/다음 시즌 조작에 적용하며 엔진의 직접 일정 API는 자동 검사·시뮬레이션에 사용할 수 있습니다.

자동 제의는 이적시장 또는 자유계약 상태에서만 검토합니다. 시장 첫날 제안 칸을 채우지 않고 첫 영입 검토를 4–9일 뒤 배치한 뒤 5–9일 간격으로 검토합니다. 한 번에 최대 1건, 시장당 최대 3건이며 매번 제의가 생기지는 않습니다. 자유계약은 시장 밖에서도 2–5일 간격, 30일 주기당 최대 5건으로 구직을 이어갑니다. 기존 새 팀 합류 90일 유예도 적용합니다.

최근 180일의 출전·평점, 포지션 적합도·보강 수요, 잠재력과 현재 실력, 구단의 이적료·장기 급여 부담을 확인합니다. 강팀은 최근 최소 8경기·600분·평점 6.9 및 현재 실력/특별한 잠재력 조건을 추가로 요구합니다. 같은 구단 자동 재접촉은 일반 구단 365일, 강팀 730일 동안 차단합니다. 플레이어가 직접 요청한 접촉은 별도로 처리합니다. 모든 값은 `scoutingRules`에서 수정하는 게임용 모델이며 현실 이적시장의 통계로 보정한 확률은 아닙니다.

## 모든 리그의 순위와 개인 순위

**리그 순위·소속팀**에서 국내·유스·유럽대회를 선택해 소속 여부와 관계없이 순위표, 득점 순위, 도움 순위를 확인합니다. 개인 순위는 해당 대회의 현재 시즌 경기만 합산하며 동점은 공동 순위입니다. 상위 20명과 순위 밖의 플레이어를 표시합니다. 같은 대회 안에서 이적하면 이전·현재 구단 기록을 합산하고 구단명을 함께 표시합니다.

득점·도움·출전 수·시간을 선수 ID별로 `state.competitionStats`에 보관합니다. 경기 결과를 저장할 때 집계하고 같은 경기 재생으로 중복 가산하지 않습니다. 국내와 유럽대회 기록은 섞지 않으며 선수 이적·은퇴 후에도 그 시즌 기록을 유지합니다. 새 시즌은 새 개인 순위 집계를 시작합니다.

**기존 저장의 한계:** v12 이전 저장은 모든 NPC의 대회별 득점/도움을 보관하지 않았으므로 과거 개인 순위를 복원할 수 없습니다. 기존 개인 커리어 기록과 리그 순위표는 유지하고 득점·도움 순위는 업데이트 이후 경기부터 집계하며 시작 날짜를 화면에 표시합니다. 다음 시즌부터 전체 시즌 순위가 집계됩니다.

자동 제의의 수준 비교는 구단의 기본 품질 대신 현재 선수단의 실제 평균 오버롤을 사용합니다. ±4 안의 후보에 가장 높은 가중치를 주고 상위 팀은 차이가 벌어질수록 더 빠르게 줄입니다. 첫 3시즌의 상위 후보 가중치는 추가로 40%를 적용합니다. 최근 출전·평점, 구단 포지션 수요·재정과 재제안 제한은 유지합니다. 24세 이하의 높은 잠재력 선수는 타고난 상한과 실력을 고려해 최대 평균 12 차이의 구단에도 유망주 후보가 될 수 있습니다. 강팀은 최근 8경기·600분·평점 6.9 등 검증도 요구하므로 잠재력만으로 오퍼를 채우지 않습니다.

## 훈련과 성장

훈련은 달력에서 실제 경과한 7일마다 누적됩니다. 슈팅 집중 훈련도 다른 능력치와 같은 성장 경로를 사용합니다. 실제 능력치 성장은 내부 소수점으로 보존하며 화면에는 훈련 이력에 따른 초록색 +와 빨간색 -를 표시합니다.

`trainingRules`의 기본 제한은 다음과 같습니다.

| 구분 | 훈련 성장 상한 |
| --- | ---: |
| 집중 훈련, 1주·해당 능력치 | +0.12 |
| 균형 훈련, 1주·능력치별 | +0.03 |
| 시즌·능력치별 누적 | +3.50 |
| 시즌·전체 능력치 증가 합계 | +8.00 |

이는 보장 증가량이 아닌 최대치입니다. 나이·DNA·코칭·훈련 종류·상한 근접도·정체 등에 따라 실제 증가량이 줄어듭니다. 부상 중인 날짜와 회복 훈련은 훈련 성장을 주지 않습니다. 훈련으로 실현 가능한 상한이 현재 능력치 아래로 내려가 건강한 선수의 성장이 영구 정지하지 않도록 연습 여지를 확보하되 타고난 상한을 넘지는 않습니다. 시즌이 바뀌면 훈련 성장 예산을 새로 시작하며 저장/불러오기로 예산을 초기화하지 않습니다.

플레이어 훈련 성장의 기본 계수는 1.8배, 경기 출전 성장의 기본 계수는 1.5배로 높였습니다. 이 배율은 실제 증가량의 보장이 아니며 NPC 성장 계수에는 적용하지 않습니다. 경기 출전 경험에 의한 성장은 훈련 예산과 별도로 처리합니다. 타고난 능력별 상한과 현재 실현 상한, 출전 경험, 프로의식·야망, 클럽 환경, 사기, 부상 누적, 노화를 반영합니다. 상한 하락만으로 현재 능력치를 바로 깎지는 않습니다. 근육·인대·큰 무릎 부상의 회복 기간과 영구 손실은 다릅니다.

## 수상과 트로피

득점왕·도움왕은 해당 대회의 실제 시즌 집계에서 공동 선두 전원에게 수여합니다. 리그·유럽대회 올해의 선수와 세계 발롱도르·코파·야신은 최소 900분의 새 평점·포지션 활약 기록을 가진 선수를 대상으로 선정합니다. 세계 평가에는 대회 수준과 실제 우승 기여도도 반영합니다. 이 상은 게임 성적 기반 평가이며 현실의 기자단·선수단 투표를 재현하지 않습니다.

푸스카스상은 페널티킥을 제외한 실제 득점 사건의 난도와 슛 유형을 비교합니다. 상세 경기에서는 실제 사건을 쓰고 세계 요약 경기는 실제로 배분된 득점에 독립 난수로 슛 유형·xG·시간을 지정합니다. 세계 후보는 상세 물리 시뮬레이션 영상이 아닌 요약 모델입니다. 후보 xG는 해당 선수와 팀 xG에 함께 합산됩니다. 가장 높은 후보 20개만 보관합니다.

정규리그·유럽대항전·MLS/USL 우승 플레이오프·브라질 C 최종 우승을 구단 트로피로 남깁니다. MLS/USL 정규리그 1위는 별도 정규 우승 기록입니다. 승격 플레이오프 승자에게 리그 우승 트로피를 부여하지 않습니다. 개인 트로피는 우승 구단에서 해당 대회를 실제로 출전한 기록이 있어야 하며 시즌 중 이적한 선수의 이전 구단 기여도도 보존합니다.

프로필 상단에 개인 수상·우승 수와 최근 경력을 강조하고 전체 경력과 세계 수상 결과는 각각 스크롤 목록으로 확인합니다. 시즌 결산에 다섯 번째 수상 화면을 추가합니다. 수상은 중복 지급하지 않으며 개인 경력은 계속 보관하고 세계 수상 목록은 최근 18시즌을 유지합니다. 이전 저장의 지나간 시즌 수상은 소급 생성하지 않고 현재 시즌의 부족한 기록은 표시합니다.

## 국내 시즌과 유럽대항전

국내 정규리그는 같은 리그의 모든 팀과 홈·원정 한 번씩 경기합니다. 브라질 세리 C는 단일 라운드로 19경기를 진행한 뒤 상위 8팀의 조별 승격 라운드를 별도로 진행합니다. 20팀의 다른 리그는 정규리그 38경기이며 MLS는 공통 홈·원정 형식의 58경기를 사용합니다. 미국의 정규리그 비대칭 대진과 K리그1 스플릿은 재현하지 않지만, 미국 우승 플레이오프는 실제 컨퍼런스로 구분합니다. 모든 리그에 게임용 8월–5월 달력을 사용하므로 한국·일본·미국·브라질의 실제 공식 경기 날짜와는 다릅니다. 국제 휴식 구간과 대륙대회 날짜를 고려하고 같은 구단의 경기 사이에는 최소 3일을 둡니다.

잉글랜드·스페인·독일·프랑스·이탈리아·포르투갈 1부에 별도 유럽대항전을 제공합니다. 최초 시즌은 게임 구단 능력·명성, 이후 시즌은 직전 국내 순위로 참가팀을 결정합니다. 대회별 일정·개인 기록·순위표를 구분합니다.

| 대회 | 참가 기준·규모 | 리그 페이즈 |
| --- | --- | --- |
| 유럽 챔피언스 대회 | 각 지원 1부의 1–4위, 24팀 | 서로 다른 8팀, 홈4·원정4 |
| 유럽 유로파 대회 | 각 1부의 5–6위, 12팀 | 서로 다른 8팀, 홈4·원정4 |
| 유럽 컨퍼런스 대회 | 각 1부의 7–8위, 12팀 | 서로 다른 6팀, 홈3·원정3 |

챔피언스 대회는 상위 8팀이 16강에 직행하고 9–24위가 8개 플레이오프를 진행합니다. 유로파·컨퍼런스는 축소 참가 규모에 맞춰 상위 4팀이 8강에 직행하고 5–12위가 4개 플레이오프를 진행합니다. 순위를 바탕으로 시드 대진을 연결하며 리그 페이즈와 토너먼트를 별도 탭으로 보여 줍니다. 결승은 중립 단판이고 그 외 단계는 홈·원정 2차전 합산입니다. 합산 동률일 때만 2차전에서 30분 연장전을 실제 시뮬레이션하고, 그래도 동률이면 승부차기로 결정합니다. 원정 다득점은 적용하지 않습니다. 연장전 득점·출전 시간·패스 등은 개인과 팀 기록에 합산하고 승부차기 득점은 분리합니다. 각 대회의 기록·대진·승자는 저장 후 재개됩니다.

[UEFA 2026/27 토너먼트 규정](https://documents.uefa.com/r/Regulations-of-the-UEFA-Champions-League-2026/27/Article-20-Match-system-knockout-phase-Online), [연장전·승부차기 규정](https://documents.uefa.com/r/Regulations-of-the-UEFA-Champions-League-2026/27/Article-21-Knockout-system-extra-time-and-penalty-shoot-outs-Online)을 참고했습니다. **참가 규모는 게임의 지원 6개국에 맞춘 24/12/12팀으로 유지합니다. 공식 36팀·국가별 배정·예선·UEFA 추첨을 그대로 구현한 것은 아닙니다.** 국제 휴식 구간을 피한 게임용 날짜를 사용합니다. 기존 저장의 진행 중인 단판 대회는 보존하고 다음 시즌부터 새 방식으로 전환합니다. 국내 컵과 국가대표 대회는 없습니다.

## 경기 기록과 도움

개인 소속팀 경기는 분 단위 조건부 확률과 시드 난수로 상세 시뮬레이션합니다. 기본 능력, 침착성·판단·지능, 피로·압박·멘탈·사기, 해외 적응, 포지션 숙련, 성격·전술·언어 효과를 행동별로 반영합니다. 감독의 포메이션과 역할·압박·전개 속도·창의성·규율 기대가 선발과 실행에 영향을 줍니다.

슈팅·유효슈팅·xG/xA·득점·도움·키패스·패스·경합·수비·선방·실점·거리·카드·출전 시간을 기록합니다. 도움은 다른 선수의 득점으로 연결된 마지막 창출 패스에 기록하며 단순 패스 수만으로 증가하지 않습니다. 도움 이벤트의 선수 ID, 개인 경기 도움, 팀 도움 합계, 커리어 도움 합계가 일치하도록 회귀 검사합니다.

상세 경기는 실제 출전한 선수·교체 시점별로 기록을 발생시키고 경기 중 부상을 가용 인원과 개인 회복 기간에 반영합니다. 최대 5명·3개 교체 시점을 공통 규칙으로 사용합니다. 팬·언론 반응은 실제 경기 사건과 결과에서 생성합니다.

전체 세계의 경기 수가 증가하므로 **개인 소속팀 이외의 경기는 별도 집계 모델**을 사용합니다. 구단 능력·홈 이점으로 득점 분포를 계산하고 선발 선수에게 득점·도움·슈팅·패스를 배분하며 골키퍼 선방은 상대 유효슈팅−득점과 맞춥니다. 개인 경기의 상세 전개 모델과 같지 않고 교체·분 단위 이벤트·NPC 경기 부상을 생성하지 않습니다. 생성 선수의 출전·성장·이적·은퇴와 클럽 재정·감독 교체는 계속 처리합니다.

공간 좌표, 실제 전술 전개 전체, VAR·오프사이드, 모든 대회의 세부 징계·등록 규정과 현실 축구 전체를 재현하지 않습니다.

## 이적·계약·세계

자동 영입 제의는 **실제 새 구단 합류일부터 90일** 동안 유예합니다. 예정 이적을 서명한 날과 실제 합류일을 구분합니다. 합류 시 기존 제의·다른 진행 협상·이전 팀에서 시작한 미해결 에이전트 접촉을 정리합니다. 같은 구단 재계약은 유예를 새로 시작하지 않고 자유계약 선수는 적용받지 않습니다. 유예 중에도 플레이어가 직접 요청하는 구단 접촉은 가능합니다.

클럽 접촉은 2–4일, 조건 협상은 1–3일 뒤 회신하며 같은 요청을 중복 제출할 수 없습니다. 이적료·분할·재판매 배분, 주급·기간·역할·포지션·보너스·인상·바이아웃·옵션·에이전트 수수료를 협상합니다. 구단·개인 조건·에이전트·메디컬 평가 뒤 최종 서명합니다. 자유계약 선수는 새 계약 전에는 출전하지 않습니다. 임대·노동 허가·실제 재정 규정·스폰서 계약은 없습니다.

생성 선수는 고유 ID와 나이·성격·DNA·포텐·출전·부상 이력을 유지합니다. 국가별 한국어 이름 자료를 사용하고 중복을 억제하지만 자료 소진 이후 완전한 무중복은 보장하지 않습니다. 신인·NPC 이적·감독 교체·재정 변화·노화·은퇴·훈련 환경 변화를 처리합니다. 뉴스와 SNS 반응은 게임 사건에서 생성하며 실제 뉴스 수집이나 외부 SNS 게시는 없습니다.

맨체스터 시티는 기존 **사용자 지정 게임 시나리오**의 최하 위상·명성·재정 잠금을 유지하며 유스에도 적용합니다. 현실 구단에 관한 사실 주장이나 평가가 아닙니다. 명문 유스 시작 후보는 모구단의 위상·명성·잠금을 확인합니다.

## v14 화면 정리와 이름 다양성

시즌 일정 목록에는 세계 리그 라운드를 표시하지 않습니다. 실제 경기 진행과 경기 결과·득점/도움 집계는 그대로 처리하며, 다음 일정 안내에는 경기 날짜를 유지합니다. 선수 검색과 구단·감독 목록은 각각 높이가 제한된 내부 스크롤을 사용합니다. 성장·선수 DNA 탭과 성장 상한·잠재력의 정확한 수치는 대시보드·프로필·선수 검색·선수 상세·오퍼에서 숨깁니다. 내부 성장 상한과 영입 평가 계산은 유지합니다.

훈련 표시는 실제 주간 훈련 이력 기준입니다. 최근 14일 안에 훈련한 항목은 초록색 +, 마지막 훈련 또는 이력 추적 시작 후 28일 이상 훈련하지 않은 항목은 빨간색 -로 표시합니다. 중간 기간에는 표시하지 않습니다. 균형 훈련은 모든 항목에 기록되고, 회복 휴식·부상 중 훈련·경기 출전만으로는 훈련 이력을 갱신하지 않습니다. 부호는 능력치 상승/하락량을 뜻하지 않으며 성장 계산·훈련 상한은 유지합니다. 이력은 저장·시즌 변경 후에도 유지합니다. 이전 저장은 업데이트 시점부터 이력을 쌓으며 과거 훈련을 추정하지 않습니다.

## v15.0 일정 선택과 시즌 결산

모든 포지션에서 경기 사이의 일정에 훈련 강도·전술 미팅·동료 관계·회복·에이전트 점검·마음가짐 선택지가 나옵니다. 첫 선택은 4일 뒤, 이후 10–16일 간격이며 시즌 막바지에는 새 선택을 예약하지 않습니다. 선택 중에는 상단 버튼이 **선택하기**로 바뀝니다. 창을 닫아 다른 정보를 확인할 수 있지만 다음 일정 전에 응답해야 합니다. 저장과 새로고침 후 미결 선택·효과·이력을 복원합니다. 경기 중 선택지는 추가하지 않으며 기존 선발·라커룸·중계·결과 흐름을 유지합니다.

선택은 체력·사기·감독 신뢰·적응·에이전트 신뢰, 실제 훈련 방향에 영향을 줍니다. 일부 선택은 다음 21일 동안 한 능력의 경기 실행 계수를 1.12배로 바꾸며 다른 준비 선택으로 대체됩니다. 준비 효과는 능력치에 즉시 더해지지 않고 기존 주간·시즌 훈련 성장 상한을 유지합니다. 엔진 직접 일정 API는 미결 선택을 기본 균형 선택으로 처리하고 자동 진행으로 기록합니다. 게임 화면은 사용자가 선택하기 전 진행하지 않습니다.

포지션별 실제 기록을 바탕으로 활약 목표를 보여 줍니다. 윙어는 돌파·키패스, 미드필더는 전개·차단, 풀백은 크로스·태클, 센터백은 클리어링·공중 경합, 골키퍼는 선방·패스, 공격수는 마무리를 평가합니다. 45분 이상 출전한 경기에서 역할 기여를 반영한 스트라이커 외 포지션의 평점 보너스는 최대 0.35입니다. 활약 지표 80 이상은 감독 신뢰·사기 각 1과 평판 0.05를 보상합니다. 골·도움·팀 기록은 실제 경기 사건에서만 합산합니다. 목표·보상·선택지·계수는 DB에서 수정할 수 있으며 현실 통계로 보정한 모델은 아닙니다.

감독 검토는 최소 재임 270일·10경기 이후 56일 간격입니다. 하위권 성적이 두 번 연속 이어질 때 부진 교체 확률을 적용하고, 구단당 시즌 내 교체는 최대 한 번으로 제한합니다. 정상 교체 확률은 검토당 0.3%, 지속 부진 추가 확률은 3.5%입니다. 기존 감독 ID·부임일을 보존합니다.

협상 기한은 시작 후 42일, 최대 제안 횟수는 8회이며 구단 접촉 2–4일·조건 회신 1–3일로 조정합니다. 시장 마감이 협상을 자동 실패시키지 않고 다음 합법적 등록일로 합류 계획을 옮깁니다. 실제 구단 합류는 등록 기간과 메디컬·재정 검사에 따릅니다. 기존 저장의 아직 유효한 진행 협상도 새 기한을 한 번 적용하며 종료된 협상을 재개하지 않습니다.

달력에서 게임 날짜가 하루라도 바뀌면 표시 월과 선택 날짜가 오늘로 이동합니다. 같은 게임 날짜 안에서는 수동 날짜·월 탐색을 유지합니다. 소속 리그가 끝나면 시즌 결산 4개 화면이 자동으로 열리고, 시즌 흐름과 시즌별 통계에서 다시 열 수 있습니다. 시즌 결과·모든 리그 순위와 득점/도움 상위 20명·개인 상세 기록·주요 경기·성장 방향·일정 선택을 확인합니다. 남은 대회가 있으면 시즌 종료까지 기록을 갱신하고, 다음 시즌을 시작하기 전에 승강·NPC 기록 초기화 이전의 최종 결과를 보관합니다. 결산은 최근 18시즌을 유지합니다. 업데이트 전의 성장·선택을 만들어 내지 않으며 이전 저장의 성장 기준은 업데이트 시점부터 표시합니다. 이전 버전의 이미 지난 시즌에 대한 결산은 소급 생성하지 않습니다.

v15 자동저장에 없던 신규 구단 색상 기준을 보충하지 않아 새로고침 시 저장 검증이 실패하고 프로필 생성 화면으로 돌아가던 문제를 수정했습니다. 기존 색상 편집값을 유지하면서 누락된 기준만 병합합니다. 경기·계약·능력치·현재 일정은 보존합니다.
