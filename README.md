v20.6.1은 같은 저장 스키마 안에서 추가된 밸런스 마이그레이션 항목을 이전 저장에 보충합니다. v20.4 등 이전 버전의 `balanceRules.previous.rules.initialOverallMax` 누락으로 자동 이어하기가 거부되던 오류를 수정하며, 기존 선수·계약·완료 경기·일정과 직접 편집한 계수는 보존합니다.

## v20.6.0 자동 이어하기·상 안내·AI 이적시장

자동 이어하기는 IndexedDB의 현재 저장·직전 저장과 로컬 보관본을 날짜순으로 검사합니다. 압축 Blob 외에 이전의 원본 커리어 객체와 JSON 문자열 payload도 읽습니다. 수동 가져오기 한도 128 MiB를 브라우저의 큰 자동저장에도 적용하던 경로를 분리하여 자동저장은 압축 해제 후 512 MiB까지 읽습니다. 저장소 열기 실패를 영구 캐시하지 않아 이후 저장 시 다시 연결할 수 있습니다. 모든 후보의 복원이 실패하면 이유를 표시하고 원본 저장·백업은 보존합니다. 브라우저가 이미 삭제한 저장이나 손상된 모든 백업을 복구하는 기능은 아닙니다.

커리어 이력·수상의 **상 안내**, 수상 내역과 시즌 결산의 상 이름을 누르면 설명과 이 커리어에서 기록된 역대 수상자가 나옵니다. 동률 공동 수상, 대회·시즌·구단을 함께 표시하고, 이적·은퇴한 선수도 당시 기록된 이름으로 남습니다. 아직 수상하지 않은 상도 안내에서 열 수 있습니다. 실제 축구의 과거 수상자를 추가하거나 커리어 시작 전 수상을 소급 생성하지 않습니다.

AI 시장은 성인 구단을 대상으로 열린 여름·겨울 시장에서 5일 간격으로 검토합니다. 기존의 선수단 초과 시 시즌 종료 무작위 이적을 대체합니다. 구단별 영입·방출은 각각 여름 최대 3명, 겨울 최대 1명, 연간 최대 4명이며 실제 거래 수는 더 적을 수 있습니다. 선수는 한 시즌 한 번만 이적하고 다음 이적까지 최소 210일을 기다립니다. 핵심 전력 상위 11명 중 연간 최대 2명만 매각할 수 있고, 높은 위상의 두 구단 간 거래는 후보 구단별 연간 1회와 별도 낮은 성사 확률을 적용합니다. 거래로 선수단이 20명 미만·25명 초과가 되지 않도록 하고 골키퍼 최소 2명을 보호합니다. 기존 저장에서 이미 초과된 인원을 강제 삭제하지 않습니다.

방출 구단은 포지션 경쟁, 잔여 계약, 시즌 시작 재정 대비 압박, 감독 부임 후 재편과 고령 선수의 세대교체를 평가합니다. 운영 원칙은 핵심 유지·유망주 육성/재판매·즉시 전력·균형 있는 세대교체로 구분합니다. 영입 구단은 해당 포지션의 인원·전력 개선, A 플랜 적합도, 육성 방향, 선수의 단계적 도전과 이적료·주급 여력을 평가합니다. 동일 국가를 우선하고 같은 대륙과 해외 후보를 제한된 범위에서 검토합니다. 부상·체력, 계약·출전 경쟁과 구단 평가가 조건에 맞지 않으면 거래하지 않습니다. 재정 부족은 매각 의사와 요구액에 영향을 주지만 핵심·인원 보호 한도를 우회하지 않습니다.

영입 예산은 시즌 시작 현금의 24%와 매각 수입의 60%를 사용하며 기존 선수 계약 협상의 예약 금액과 현금 유보를 고려합니다. 이적료는 구매 구단에서 차감하고 판매 구단에 같은 금액을 지급합니다. 계약은 2–4년, 주급은 능력·연령·잠재력·활약을 반영한 가치에 기반하고 주간 구단 비용에 반영됩니다. 기존 선수의 계약을 최초로 추적할 때는 현재 날짜부터 1–4년을 부여하며 과거 실제 계약을 추정했다고 표시하지 않습니다. 잔류 선수의 만료가 가까운 계약은 시즌 경계에서 갱신하고, 현재 시장 내 만료된 계약의 거래는 이적료가 없습니다. 시장가는 추적 시작 시즌부터 연 2.5%, 최대 1.75배까지 완만하게 상승하며 플레이어와 AI 양쪽에 적용합니다.

이적 후 능력치·누적 기록·국적·고유 ID와 국가대표 명단 참조를 유지하고 새 구단에 적응합니다. 기존 주장 이탈 시 해당 자리를 공석으로 남기고 정해진 등록일에 새 주장단을 선임합니다. 이적협상 화면에 최근 AI 거래 600건과 방출 배경을, AI 선수 팝업에 추적된 계약을 표시합니다. 신규 규칙은 `npcMarketRules`, 상 설명은 `awardTypes`, 자동저장 한도는 `storageRules`에서 편집합니다. 이전 저장의 경기·플레이어 계약과 사용자 DB 설정을 보존하면서 새 추적 필드를 추가합니다.

수치의 참고 방향은 [FIFA 2025 국제 이적 보고서](https://inside.fifa.com/transfer-system/media-releases/international-transfers-reach-historic-high-2025)와 [CIES의 선수단 안정성 연구](https://football-observatory.com/New-Monthly-Report-highlights-the-importance-of)입니다. FIFA 자료는 국제 이적만 다루고, CIES의 해당 비교는 2009–2017년 표본입니다. 이 구현의 구단별 상한·성사 확률·물가는 게임의 규모와 안정성을 위한 가정이며 실제 구단 내부 의사결정이나 국내외 시장 전체의 통계를 그대로 재현한 수치가 아닙니다. 임대·선수 교환·별도 무소속 AI 풀·현실의 재정 규정·등록 규정은 구현하지 않습니다. 기존 시나리오의 고정 위상/재정 정책도 유지합니다.

검증: `node tests/engine.test.cjs`, `node --test tests/npc-market.test.cjs tests/save-import.test.cjs`, `node tests/browser-autosave-market-awards.cjs`. AI 거래의 금액 보존·선수 ID·능력치/기록 보존·여름/겨울 상한·반복 거래·예산·재정 매각·골키퍼 보호·이전 저장 초기화·물가 상한과 PC/모바일의 이전 자동저장·JSON payload·독립 용량 경로·수상 팝업·AI 거래 표시·새로고침·손상된 최신 저장의 백업 복원을 검사합니다. 브라우저 검사는 기존 v20.5.0 Git 커밋을 읽고 실제 IndexedDB를 사용하며 새 JSON 파일을 내보내지 않습니다.

## 실행과 저장

`index.html`을 브라우저에서 열면 실행됩니다. 외부 라이브러리·서버·빌드가 필요 없습니다. IndexedDB에 현재 자동저장과 직전 저장을 같은 트랜잭션으로 보관하고, 최신 저장을 복원하지 못하면 이전 저장도 검사합니다. 압축한 로컬 보관본은 브라우저 용량 안에 들어갈 때 보조로 저장합니다. 확장된 전체 커리어는 로컬 보관 한도를 넘을 수 있으므로 IndexedDB와 JSON 내보내기/불러오기를 사용합니다. 자동 저장이 불가능하면 JSON 내보내기를 사용할 수 있습니다. 계정 클라우드 동기화는 없습니다.

저장 스키마는 13입니다. 이전 schema 1–12의 선수·계약·능력치·개인 경기 기록·중계 상태를 보존하면서 새 DB로 확장합니다. v12/schema 11 및 v13/schema 12 저장은 현재 일정과 경기 기록을 그대로 유지합니다. 더 이전 저장은 지원 리그의 구단 소속을 새 시즌 명단에 맞추고 미래 일정을 다시 만듭니다. 이미 끝난 경기는 결과·날짜를 유지하며 새 리그 구성과 맞지 않는 경기는 과거 경기로 보관합니다. 지나간 날짜에 새 경기를 추가하지 않습니다. 현재 소속 구단이 지원 명단에서 제외된 경우 `seasonCatalog.clubMigrations`의 대응 구단으로 옮기고 메시지함에 알립니다. 사용자 추가 리그·구단의 ID도 보존합니다.

현재 시즌의 세계 결과는 요약으로 저장하고 개인 경기 보고서는 전체 기록을 유지합니다. 세계 연감은 최근 40시즌, 세계 이벤트는 최근 1,200개, 전체 리그 결과 아카이브는 최근 18시즌을 유지합니다. JSON 불러오기 제한은 128MiB입니다. 잘못된 파일은 검증 후 거부하고 현재 커리어를 변경하지 않습니다. 브라우저 데이터 삭제·저장 제한 설정까지 보존을 보장하지는 않습니다.

웹 실행에서는 시작 시, 다시 화면으로 돌아올 때, 2분 간격으로 같은 주소의 배포 버전을 캐시 없이 확인합니다. 더 높은 버전을 발견하면 화면 하단에 **새 버전이 출시되었습니다. 업데이트해주세요.** 안내와 업데이트 버튼을 표시합니다. 버튼을 누르면 진행 중인 경기·플레이오프·선택을 저장하고 로딩을 표시한 뒤 새 페이지를 불러옵니다. 저장 실패 시 현재 화면을 유지하고 재시도를 안내합니다. 오프라인 파일 실행에서는 버전을 확인하지 않으며 네트워크 오류도 게임 진행을 막지 않습니다. 이 기능이 없던 기존 화면은 v16을 한 번 새로고침한 다음 배포부터 알림을 받습니다.

## 국가·리그·클럽 탐색

이적 접촉, 팀·리그, 축구계의 선수·구단 검색과 새 커리어의 선호 리그·드림클럽은 국가 → 리그 → 클럽 순서로 탐색합니다. 리그는 국가 안에서 프로 1부·2부·하부, 유소년, 승강 대회 순으로 정렬하고 유럽대항전은 별도 항목으로 분류합니다. 이탈리아·포르투갈과 커리어의 승강 결과도 반영합니다. 상위 필터를 바꾸면 범위 밖의 하위 선택을 해제하며, 에이전트 추천 구단을 선택하면 그 구단의 국가·리그로 이동합니다. 선수와 구단 검색 필터는 서로 독립적입니다.

선호 리그·드림클럽은 전체 지원 국내 리그·성인 클럽에서 선택하며 미정도 유지합니다. 국적 선택과 희망 국가 선택은 별개입니다. 경기 일정·결과의 대회 필터에도 국가 선택이 있습니다. 팀·리그의 클럽 선택 후 정보 버튼으로 구단 상세 정보를 엽니다. 탐색 필터는 경기·계약·선수 데이터를 바꾸지 않습니다.

v19.1.2에서는 브라우저 보조 기능이 화면 갱신 뒤 국가 선택을 자동으로 초기화하는 이벤트를 보내도 사용자가 고른 국가를 유지합니다. 직접 선택한 국가를 기준으로 표시와 리그·클럽 목록을 일치시키며, 프로필·에이전트·팀·축구계·일정·시즌 결산에 적용합니다. 실제 키 입력과 자동 초기화 이벤트 재생으로 PC·모바일을 검증합니다. 저장 스키마와 경기 엔진은 그대로입니다.

v19.1.3에서는 기존 저장의 K리그1 참가 팀 수가 현재 규칙과 달라도 시즌을 마칠 수 있습니다. 새 승강 플레이오프의 상위 리그 참가자는 실제 순위표의 하위 순위로 계산합니다. 이미 생성된 경기와 결과는 보존하고, 존재하지 않는 참가 순위를 요구해 생성조차 되지 못한 경로만 제외합니다. 시즌 종료일에 멈춘 저장도 불러올 때 완료 상태를 복구하며, 다음 일정이 없는 경우 일정 화면에서 오류가 발생하지 않습니다. 시즌 사이의 남은 훈련·회복을 처리한 뒤 승강 결과를 반영합니다. 저장 스키마는 그대로입니다.

메뉴별 페이지 바는 본문 왼쪽 유격 없이 상단 바와 정렬되고, 메뉴 이름 아래 같은 폭의 페이지 격자를 표시합니다. 현재 페이지는 배경·굵기·밑줄로 구분하며 키보드 포커스와 PC·모바일 배율을 지원합니다.

## 화면과 중계

프로필·성격 선택 화면에서도 상단 설정 버튼으로 화면 배치, 인터페이스 크기, 금액 단위를 변경할 수 있습니다. 돌아가기·설정 복원 후에도 작성 중인 프로필과 선택 단계를 유지합니다. 인터페이스 크기는 80–200%이며 자동/PC 화면 배치를 지원합니다.

텍스트 중계는 기존 중계창과 버튼을 유지하면서 새 이벤트만 추가합니다. 하단을 보고 있으면 새 내용을 즉시 따라가고, 위로 스크롤해 이전 내용을 읽으면 읽는 위치를 유지합니다. 일시정지·이어보기·경기 종료에서도 중계창과 페이지 스크롤·버튼 포커스를 유지합니다. 종료 시 버튼을 비활성화하여 화면 높이가 갑자기 줄지 않게 합니다.

중계 속도는 0.5배(2초), 1배(1초), 2배(0.5초)입니다. 일시정지 중에도 변경할 수 있고 새로고침 후 선택을 복원합니다. 창이 숨겨지면 중계를 멈춥니다. 경기 준비 때 결과를 한 번 계산하므로 중계 재개·스킵은 기록을 중복 누적하지 않습니다.

버튼은 호버·누름·키보드 포커스를 구분하고, 탭과 선택 상태는 색으로 표시합니다. 주요 버튼에 마우스를 두거나 키보드로 포커스하면 기능 설명이 나타납니다. 점선 밑줄이 있는 구단·리그·선수·감독 이름을 누르면 상세 정보 팝업을 볼 수 있습니다. 구단 팝업에는 현재 선수단 평균·구단 환경·감독·선수 명단이 있고, 리그 순위·득점·도움 기록이나 선수단 검색으로 이동할 수 있습니다. 연속해서 연 정보는 팝업의 이전 정보 버튼으로 돌아가며, 닫기/Escape 후 원래 버튼으로 포커스가 돌아갑니다.

xG·xA·오버롤·경기력 등 주요 수치의 점선 설명 버튼은 호버 또는 클릭으로 의미를 안내합니다. 모바일은 탭으로 정보 팝업을 엽니다. 툴팁은 화면 가장자리와 200% 배율에 맞춰 배치하며, 스크롤·화면 전환·Escape 시 닫힙니다. 시스템의 모션 줄이기 설정에서는 새 누름·팝업 애니메이션을 생략합니다. 설명 데이터는 `ui.interactions`에 있고 이전 자동저장에 추가합니다. 이 설명·효과 기능은 경기 계산이나 저장 스키마를 변경하지 않습니다.

## 필수 응답과 영입 제안

유효한 미응답 오퍼, 플레이어 답변/서명을 기다리는 협상, 현재 감독의 계획, 재계약 의사 확인이 있으면 상단 일정 버튼을 **응답하기**로 바꿉니다. 누르면 메시지함의 답변 필요 필터에서 해당 메시지를 바로 엽니다. 읽음 표시는 응답을 대신하지 않습니다. 오퍼는 협상·거절·나중에 검토로 처리할 수 있고 보류한 오퍼는 원래 기한까지 시장에 남습니다. 조건 합의 후 메디컬만 보류된 협상은 일정 진행을 막지 않습니다. 회복 중 3일 간격(남은 기한이 짧으면 기한 당일)으로 자동 재검사하며 협상 횟수를 소모하지 않습니다. 통과하면 서명 응답을 요청하고, 계약 조건에도 이견이 있으면 기존처럼 조건 응답이 필요합니다. 기한까지 통과하지 못하면 협상이 종료됩니다. 기존 저장의 멈춘 메디컬 보류도 불러올 때 재검사를 예약합니다. 협상 회신 대기 중에는 일정을 진행하며 새 답변/서명이 필요하면 다시 응답 버튼을 표시합니다. 만료·철회·서명·이적 예약 상태와 과거 감독의 계획은 진행을 막지 않습니다.

계약 만료 90일 전부터 재계약 의사를 한 번 묻습니다. 협상을 시작하거나 재계약하지 않기를 선택합니다. 자동 재계약은 하지 않습니다. 이 게이트는 게임 화면의 일정/다음 시즌 조작에 적용하며 엔진의 직접 일정 API는 자동 검사·시뮬레이션에 사용할 수 있습니다.

자동 제의는 이적시장 또는 자유계약 상태에서만 검토합니다. 시장 첫날 제안 칸을 채우지 않고 첫 영입 검토를 4–9일 뒤 배치한 뒤 5–9일 간격으로 검토합니다. 한 번에 최대 1건, 시장당 최대 3건이며 매번 제의가 생기지는 않습니다. 자유계약은 시장 밖에서도 2–5일 간격, 30일 주기당 최대 5건으로 구직을 이어갑니다. 기존 새 팀 합류 90일 유예도 적용합니다.

최근 180일의 출전·평점, 포지션 적합도·보강 수요, 잠재력과 현재 실력, 구단의 이적료·장기 급여 부담을 확인합니다. 강팀은 최근 최소 8경기·600분·평점 6.9 및 현재 실력/특별한 잠재력 조건을 추가로 요구합니다. 같은 구단 자동 재접촉은 일반 구단 365일, 강팀 730일 동안 차단합니다. 플레이어가 직접 요청한 접촉은 별도로 처리합니다. 모든 값은 `scoutingRules`에서 수정하는 게임용 모델이며 현실 이적시장의 통계로 보정한 확률은 아닙니다.

## 모든 리그의 순위와 개인 순위

**리그 순위·소속팀**에서 국내·유스·유럽대회를 선택해 소속 여부와 관계없이 순위표, 득점 순위, 도움 순위를 확인합니다. 개인 순위는 해당 대회의 현재 시즌 경기만 합산하며 동점은 공동 순위입니다. 상위 20명과 순위 밖의 플레이어를 표시합니다. 같은 대회 안에서 이적하면 이전·현재 구단 기록을 합산하고 구단명을 함께 표시합니다.

득점·도움·출전 수·시간을 선수 ID별로 `state.competitionStats`에 보관합니다. 경기 결과를 저장할 때 집계하고 같은 경기 재생으로 중복 가산하지 않습니다. 국내와 유럽대회 기록은 섞지 않으며 선수 이적·은퇴 후에도 그 시즌 기록을 유지합니다. 새 시즌은 새 개인 순위 집계를 시작합니다.

**기존 저장의 한계:** v12 이전 저장은 모든 NPC의 대회별 득점/도움을 보관하지 않았으므로 과거 개인 순위를 복원할 수 없습니다. 기존 개인 커리어 기록과 리그 순위표는 유지하고 득점·도움 순위는 업데이트 이후 경기부터 집계하며 시작 날짜를 화면에 표시합니다. 다음 시즌부터 전체 시즌 순위가 집계됩니다.

자동 제의의 수준 비교는 구단의 기본 품질 대신 현재 선수단의 실제 평균 오버롤을 사용합니다. ±4 안의 후보에 가장 높은 가중치를 주고 상위 팀은 차이가 벌어질수록 더 빠르게 줄입니다. 첫 3시즌의 상위 후보 가중치는 추가로 40%를 적용합니다. 최근 270일의 기록을 평가해 비시즌에 이전 시즌 실적이 너무 빨리 사라지지 않도록 합니다. 일반 후보는 3경기·180분·평점 6.35, 강팀은 6경기·450분·평점 6.65 등 검증을 요구합니다. 최소 포지션 수요는 0.05, 같은 구단의 재제안 제한은 일반 240일·강팀 365일입니다. 24세 이하의 높은 잠재력 선수는 타고난 상한과 실력을 고려해 최대 평균 12 차이의 구단에도 유망주 후보가 될 수 있습니다. 잠재력만으로 오퍼를 채우지 않으며 전술 적합도·재정·실력 격차 조건을 유지합니다.

## 체계적인 개인 훈련과 성장

독립 메뉴 **훈련센터**에서 주목표·보조목표·강도·훈련 주기를 정합니다. 코치 추천은 수정 가능한 초안이며 적용 버튼을 눌러야 효력이 생깁니다. 개요에는 훈련센터 이동 버튼을 표시하고 현재 계획·피로·능력 변화는 훈련센터에서 확인합니다. 주목표가 회복 휴식이면 개인 성장 훈련을 중단합니다.

발전 중심·균형 주기·경기 준비의 7일 패턴을 28일 단위로 검토합니다. 달력에서 실제 지나간 날짜마다 그날의 계획·경기력·누적 피로를 기록합니다. 경기일에는 부하를 낮추고 전날은 조절하며 실제 출전 후 1–2일은 회복을 우선합니다. 부상 중에는 재활, 경기력 55 미만 또는 누적 피로 85 이상이면 보호 회복으로 전환합니다. 다음 7일 미리보기는 현재 일정에 따른 전망이며 이후 출전·부상·추가 일정은 달라질 수 있습니다.

가벼운 강도는 성장량과 피로를 줄이고, 집중 강도는 건강하고 일정이 여유로울 때 성장 훈련량을 늘리지만 피로를 더 쌓습니다. 누적 피로는 훈련 효율을 낮추고 기존 경기 중 부상 확률의 부하 항에 반영됩니다. 별도의 훈련 중 부상 사건이나 물리적인 훈련 시뮬레이션은 없습니다. 실제 포지션 훈련을 소화한 날짜에만 감독 신뢰가 소폭 증가합니다. 같은 계획을 꾸준히 진행하면 제한된 연속 훈련 보너스를 받습니다.

실제 하루의 훈련량을 누적해 7일마다 성장에 반영하고 주간 코치 기록을 남깁니다. 주중에 목표를 바꾸면 바꾸기 전 훈련과 이후 훈련을 함께 반영합니다. 선택 버튼만 반복해서 눌러 능력치·피로·성장 예산을 초기화할 수 없습니다. 현재 계획은 평가 후에도 계속되며 28일마다 검토 메시지를 보냅니다. 최근 14일 훈련과 주간 평가 12개를 보관합니다.

슈팅을 포함한 실제 성장은 내부 소수점으로 보존합니다. 화면의 초록색 +와 빨간색 −는 최근 훈련·장기 미훈련 표시이며, 주간 코치 기록의 기호는 실제 평가 기간의 상승·하락 방향입니다. 정확한 소수 성장량이나 타고난 상한은 노출하지 않습니다.

기존 `trainingRules`의 집중 능력 1주 최대 +0.12, 시즌 능력별 +3.5, 시즌 전체 합계 +8 상한을 유지합니다. 새 혼합 주기는 균형 기본 한도 +0.03에 누적 항목별 훈련량을 반영해 주간 한도를 배분하며 능력별 최대 +0.12를 넘지 않습니다. 나이·DNA·코칭·성장 상한·피로·훈련량에 따라 실제 증가량은 더 적습니다. 부상 날짜와 회복은 성장 훈련량을 주지 않습니다. 평가일에 부상 중이어도 그 주에 이미 소화한 건강한 날짜의 훈련량은 반영합니다. 경기 경험 성장은 별도로 반영하며 플레이어 훈련 1.65배·경기 경험 1.4배 계수를 적용합니다. 시즌 예산은 저장·불러오기·계획 교체로 재설정되지 않습니다.

이전 저장은 선택 중이던 훈련을 주목표로 옮깁니다. 선수·계약·경기·기존 성장 예산은 유지하며 이미 누적된 미완료 7일 훈련은 이전 선택 기준으로 변환합니다. 당시 날짜별 훈련·피로 기록은 없으므로 업데이트 시점부터 새 이력을 기록합니다. 규칙·강도·주기·선택지·문구는 `trainingProgramRules`와 `ui.labels`에서 관리합니다.

## 에이전트 위임과 클럽 접촉

이적·협상의 에이전트는 출전과 성장·보수·장기 안정·다음 도약의 우선순위와 비공개 탐색·직접 제안·공개 구직의 접촉 방식을 정합니다. 탐색 방식은 회신 속도·관심 가능성·감독/에이전트 관계 비용을 다르게 적용합니다. 에이전트별 접촉 한도는 2–4개이며 같은 클럽 재접촉 대기 기간은 14일입니다. 접촉을 철회하면 빈 자리가 생기지만 사용한 신뢰와 재접촉 대기 기간을 돌려주지 않습니다.

클럽 검색은 클럽·리그·국가명을 찾고, 리그 필터와 클럽명 가나다순을 지원합니다. 현재 실제 선수단 평균 오버롤·전술 적합도·예상 역할·주급·성장 환경을 보고 접촉할 수 있습니다. 접촉마다 에이전트와 전략을 보관해 회신 전 전략 변경이 진행 중 요청을 바꾸지 않습니다. 접촉 결과에는 실제 수요·재정과 능력 차이를 반영하고 확률 검토를 적용합니다. 강팀의 기존 출전·평점·능력/잠재력 요구를 우회하지 않으므로 접촉이나 상담 추천은 오퍼를 보장하지 않습니다.

상담은 현재 우선순위에 맞는 후보 보고서를 만들며 14일 동안 반복할 수 없습니다. 상담만으로 신뢰를 올리지 않습니다. 에이전트 교체는 접촉·협상·예약 이적을 마친 뒤 가능하며 교체 후 60일 동안 다시 바꿀 수 없습니다. 이전 저장과 신규 커리어의 첫 위임 선택은 즉시 가능합니다.

각 협상에서는 별도의 우선순위와 타협형·균형형·강경형 태도를 정합니다. 에이전트의 능력·신뢰에 따라 주급 여지, 실력/전술이 받쳐주는 역할 한 단계, 장기 계약 위험 부담 또는 바이아웃 기준을 조율합니다. 전체 구단 계약 예산·이적료·메디컬·역할에 따른 실제 출전 경쟁은 유지하며 모든 조건이 동시에 유리해지지는 않습니다. 추천 조건은 제출 전 수정 가능한 초안입니다. 강경 제안은 신뢰를 소모하고 회신이 느리며, 반복된 무리한 요구로 구단 관계가 낮아지면 협상이 중단됩니다. 메디컬 재검사와 회신 대기는 관계를 소모하지 않습니다.

위임 관계와 업무 범위는 [FIFA의 에이전트 위임 설명](https://ipt.fifa.com/transfer-system/agents/education/fifa-parent-education-on-football-agents/entering-into-a-representation-relationship), 훈련·경기 부하와 회복은 [FIFPRO의 부하 모니터링](https://www.fifpro.org/en/what-we-do/workload-monitoring)을 참고한 게임 설계입니다. 에이전트 능력·수수료·확률·훈련 계수는 실제 규정이나 실측 통계가 아닌 게임용 모델이며 `agentSystem`, `agents.skills`에서 수정합니다. 실제 이적 업무·의료·훈련 처방을 재현하지 않습니다.

## 수상과 트로피

득점왕·도움왕은 해당 대회의 실제 시즌 집계에서 공동 선두 전원에게 수여합니다. 리그·유럽대회 올해의 선수와 세계 발롱도르·코파·야신은 최소 900분의 새 평점·포지션 활약 기록을 가진 선수를 대상으로 선정합니다. 세계 평가에는 대회 수준과 실제 우승 기여도도 반영합니다. 이 상은 게임 성적 기반 평가이며 현실의 기자단·선수단 투표를 재현하지 않습니다.

푸스카스상은 페널티킥을 제외한 실제 득점 사건의 난도와 슛 유형을 비교합니다. 상세 경기에서는 실제 사건을 쓰고 세계 요약 경기는 실제로 배분된 득점에 독립 난수로 슛 유형·xG·시간을 지정합니다. 세계 후보는 상세 물리 시뮬레이션 영상이 아닌 요약 모델입니다. 후보 xG는 해당 선수와 팀 xG에 함께 합산됩니다. 가장 높은 후보 20개만 보관합니다.

정규리그·유럽대항전·MLS/USL 우승 플레이오프·브라질 C 최종 우승을 구단 트로피로 남깁니다. MLS/USL 정규리그 1위는 별도 정규 우승 기록입니다. 승격 플레이오프 승자에게 리그 우승 트로피를 부여하지 않습니다. 개인 트로피는 우승 구단에서 해당 대회를 실제로 출전한 기록이 있어야 하며 시즌 중 이적한 선수의 이전 구단 기여도도 보존합니다.

프로필 상단에 개인 수상·우승 수와 최근 경력을 강조하고 전체 경력과 세계 수상 결과는 각각 스크롤 목록으로 확인합니다. 시즌 결산에 다섯 번째 수상 화면을 추가합니다. 수상은 중복 지급하지 않으며 개인 경력은 계속 보관하고 세계 수상 목록은 최근 18시즌을 유지합니다. 이전 저장의 지나간 시즌 수상은 소급 생성하지 않고 현재 시즌의 부족한 기록은 표시합니다.

## 국내 시즌과 유럽대항전

국내 정규리그는 같은 리그의 모든 팀과 홈·원정 한 번씩 경기합니다. 브라질 세리 C는 단일 라운드로 19경기를 진행한 뒤 상위 8팀의 조별 승격 라운드를 별도로 진행합니다. 20팀의 다른 리그는 정규리그 38경기이며 MLS는 공통 홈·원정 형식의 58경기를 사용합니다. 미국의 정규리그 비대칭 대진과 K리그1 스플릿은 재현하지 않지만, 미국 우승 플레이오프는 실제 컨퍼런스로 구분합니다. 모든 리그에 게임용 8월–5월 달력을 사용하므로 한국·일본·미국·브라질의 실제 공식 경기 날짜와는 다릅니다. 국제 휴식 구간과 대륙대회 날짜를 고려하고 같은 구단의 경기 사이에는 최소 3일을 둡니다.

잉글랜드·스페인·독일·프랑스·이탈리아·포르투갈 1부에 별도 유럽대항전을 제공합니다. 최초 시즌은 게임 구단 능력·명성, 이후 시즌은 직전 국내 순위로 참가팀을 결정합니다. 대회별 일정·개인 기록·순위표를 구분합니다.

| 대회 | 참가 기준·규모 | 리그 페이즈 |
| --- | --- | --- |
| 유럽 챔피언스 대회 | 각 지원 1부의 1–4위, 24팀 | 서로 다른 8팀, 홈4·원정4 |
| 유럽 유로파 대회 | 각 1부의 5–6위, 12팀 | 서로 다른 8팀, 홈4·원정4 |
| 유럽 컨퍼런스 대회 | 각 1부의 7–8위, 12팀 | 서로 다른 6팀, 홈3·원정3 |

챔피언스 대회는 상위 8팀이 16강에 직행하고 9–24위가 8개 플레이오프를 진행합니다. 유로파·컨퍼런스는 축소 참가 규모에 맞춰 상위 4팀이 8강에 직행하고 5–12위가 4개 플레이오프를 진행합니다. 순위를 바탕으로 시드 대진을 연결하며 리그 페이즈와 토너먼트를 별도 탭으로 보여 줍니다. 결승은 중립 단판이고 그 외 단계는 홈·원정 2차전 합산입니다. 합산 동률일 때만 2차전에서 30분 연장전을 실제 시뮬레이션하고, 그래도 동률이면 승부차기로 결정합니다. 원정 다득점은 적용하지 않습니다. 연장전 득점·출전 시간·패스 등은 개인과 팀 기록에 합산하고 승부차기 득점은 분리합니다. 각 대회의 기록·대진·승자는 저장 후 재개됩니다.

[UEFA 2026/27 토너먼트 규정](https://documents.uefa.com/r/Regulations-of-the-UEFA-Champions-League-2026/27/Article-20-Match-system-knockout-phase-Online), [연장전·승부차기 규정](https://documents.uefa.com/r/Regulations-of-the-UEFA-Champions-League-2026/27/Article-21-Knockout-system-extra-time-and-penalty-shoot-outs-Online)을 참고했습니다. **참가 규모는 게임의 지원 6개국에 맞춘 24/12/12팀으로 유지합니다. 공식 36팀·국가별 배정·예선·UEFA 추첨을 그대로 구현한 것은 아닙니다.** 국제 휴식 구간을 피한 게임용 날짜를 사용합니다. 기존 저장의 진행 중인 단판 대회는 보존하고 다음 시즌부터 새 방식으로 전환합니다. 국내 컵은 없으며 국가대표 대회는 아래의 별도 엔진으로 진행합니다.

## 국가대표 · 네이션스

대표팀은 UEFA 32개, AFC 24개, CAF 24개, CONMEBOL 10개, CONCACAF 16개, OFC 8개로 **총 114개**입니다. 기존 프로필의 8개 국적과 국내 리그 범위는 유지하며, 모든 대표팀은 국가대표 메뉴에서 탐색합니다. `nationalTeams`, `nationalCompetitions`, `nationalRules`와 `ui.labels`가 데이터·계수·문구를 관리합니다. 대표팀은 구단과 다른 ID를 가지며 이적 후보에 포함하지 않습니다.

최근 180일의 구단 출전·평점, 포지션 실력과 경쟁 순위, 대표팀 감독의 신뢰·폼·유망주 선호, 해당 포지션의 가용 자원을 평가합니다. 좋은 폼, 감독의 높은 평가, 보강 필요 중 한 경로를 충족하면서 대표팀 명단 경쟁을 통과해야 소집됩니다. 충분히 뛰지 않았어도 포지션 경쟁자를 뚜렷하게 앞서는 선수는 감독 평가 경로로 선발될 수 있습니다. 부상·낮은 경기력·최소 나이는 소집을 제한합니다. 감독 평가와 소집 이유를 화면과 메시지함에서 확인합니다. 각 소집은 26명이며 GK 3명·수비 8명·중원 7명·공격 8명을 배정합니다.

지원 구단의 생성 선수 ID를 참조하고, 리그를 구현하지 않은 국가와 부족한 포지션은 대표팀 전력에 맞춘 생성 예비 선수로 보완합니다. 구단 소속을 대표팀으로 옮기지 않습니다. 소집 중 플레이어는 구단 경기에서 빠지고 구단 경기는 세계 요약 모델로 진행합니다. 대표팀 출전의 체력·훈련 피로·부상·명성은 같은 선수에게 반영하며, 구단 감독 신뢰·구단 징계·구단 출전/득점 보너스는 대표팀 경기로 바꾸지 않습니다. 대표팀 감독 신뢰와 경고/출전 정지는 별도로 저장합니다. NPC의 구단 일정과 대표팀 출전을 모두 물리적으로 조정하는 등록·차출 모델은 구현하지 않습니다.

본선 토너먼트는 중립 단판이며 동점이면 연장 후 승부차기로 결정합니다. 플레이어 경기는 기존 상세 경기·전술판·라커룸·중계·결과를 사용합니다. 나머지 A매치는 기존 세계 집계 모델을 사용합니다. 승부차기는 팀 골·개인 득점·도움에 합산하지 않습니다. `state.nations.history`의 A매치 기록은 구단의 `player.history`와 분리하고, 경기 일정·결과와 달력에서는 함께 확인합니다. 국가대표 메뉴에서 출전·골·도움·소집 이력·참여한 우승을 확인합니다. 대회별 개인 순위와 조별 순위도 구단 승점·개인 순위에 섞이지 않습니다.

**현실 데이터와 모델의 경계:** 전력·명성·위상은 [FIFA 2025년 7월 남자 랭킹](https://inside.fifa.com/fifa-rankings/world-ranking/men/news/coca-cola-mens-world-ranking-july-2025-argentina-top-croatia)과 알려진 대회 성과를 참고한 게임용 추정치입니다. 공식 FIFA 점수나 실시간 선수단 평가가 아닙니다. 감독과 선수는 생성 인물입니다. 유니폼은 국가별 대표 주색·보조색의 화면용 근사치이며 공식 엠블럼·특정 시즌의 무늬를 복제하지 않습니다. 홈/대체 유니폼을 표시하고 전술판에서 주색이 가까운 국가를 만나면 원정 배색을 교환합니다.

월드컵 형식은 [FIFA의 48개국 안내](https://www.fifa.com/en/articles/article-fifa-world-cup-2026-mexico-canada-usa-new-format-tournament-football-soccer), 유로는 [UEFA](https://www.uefa.com/euro2028/news/028f-1b599fe02d18-0c758142f5e4-1000--euro-2028-all-you-need-to-know/), 아시안컵은 [AFC](https://www.the-afc.com/en/national/afc_asian_cup.html/news/afc-asian-cup-saudi-arabia-2027%E2%84%A2-primed-for-spectacular-showdowns), 골드컵은 [CONCACAF](https://www.concacaf.com/competitions/gold-cup/news/2025-concacaf-gold-cup-all-you-need-to-know)를 참고했습니다. 지역 예선은 정규화한 미니 조별 순위로 UEFA 16·AFC 9·CAF 9·남미 6·북중미 7·OFC 1팀을 선발하는 게임 모델입니다. 실제 개최국 자동 진출·지역별 다단계 예선·대륙간 플레이오프·공식 추첨표는 구현하지 않습니다. 예선 기록이 없는 이전 저장은 전력에 따른 시드로 본선 참가국을 채웁니다. 대륙 컵 참가국도 지원 국가에서 전력 시드로 선발합니다. 코파의 초청국, 네이션스 리그의 하위 리그·승강·공식 8강 방식은 구현하지 않습니다.

[FIFA 국제 경기 캘린더](https://inside.fifa.com/news/fifa-council-approves-international-match-calendars)는 참고 자료이며, 구단 일정과 기존 저장을 보존하기 위해 기존 게임의 국제 휴식기와 DB의 대회 날짜를 사용합니다. 매년 실제 개최 일정·제도 변경을 자동 추적하지 않습니다. 새 커리어는 2026-08-01 시작이므로 첫 월드컵은 2030년입니다. 아시안컵·아프리카 컵·골드컵은 2027년, 유로·코파·OFC 컵은 2028년부터 생성합니다.

**저장:** 스키마 13을 유지합니다. 이전 저장의 구단 일정·능력치·계약·개인 기록을 그대로 두고 대표팀 상태와 현재 날짜 이후의 이벤트만 추가합니다. 이미 시작한 본선은 소급 생성하지 않습니다. 소집·조별 결과·진행 중 대진·승부차기·중계 상태를 저장 후 재개합니다. 대표팀/선수/대회 ID와 명단·날짜·경기/개인 합계·손상된 저장을 검증하며 사용 중인 국가·선수 참조를 삭제한 DB는 거부합니다.

검증은 `node --test tests/nations.test.cjs`와 `node tests/browser-nations.cjs`를 사용합니다. 새 회귀 7개는 대표팀의 구단 이적 차단·114개국 데이터·소집/결장·구단과 A매치 분리·월드컵 104경기·각 대륙 컵과 네이션스 결승·이전 저장의 미래 이벤트·손상된 명단을 검사하며 모두 통과했습니다. 기존 엔진 7개, 시장 밸런스 4개, 커리어 특성 6개, 저장 불러오기 6개도 통과했습니다. 브라우저 검사는 PC와 Pixel 7 모바일에서 이전 배포 복원, 100/200% 배율, 유니폼·소집 명단·전술판·라커룸·중계·결과, A매치 저장 후 재개, 월드컵 12개 조를 확인했고 스크립트 오류는 0개입니다. `NATIONS_LEGACY_HTML`과 `TEST_OUTPUT_DIR`로 이전 배포 파일과 검증 이미지 경로를 지정합니다.

## 승강과 플레이오프

위 표에 등록된 디비전 사이의 승강 경로를 연결합니다. 누락된 2부 7개와 J3의 전체 참가 구단·유스를 추가하며 기존 구단 ID는 재사용합니다. 성인 540개 구단이 정규리그에 참여합니다. 한국·일본·잉글랜드·스페인·독일·프랑스·이탈리아·포르투갈·브라질의 경로와 미국의 우승 플레이오프는 postseasonRules에서 관리합니다.

플레이오프는 별도 대회 ID의 실제 경기로 생성합니다. 개인 소속팀은 기존 상세 경기·중계·기록을 사용하며, 다른 경기는 세계 집계 모델을 사용합니다. 합산 점수·상위 순위 우선·연장·승부차기·3전 2선승을 구분하고, 승부차기는 득점·도움에 더하지 않습니다. 플레이오프 경기와 개인 순위가 정규리그 승점에 섞이지 않습니다. 대진·예정 경기·승강 결과는 소속팀 화면과 시즌 회고에서 확인합니다. 경기별로 저장·재개하며 승강은 시즌 전환 때 한 번 적용하고 유스 소속·차기 일정·강등 연봉 조항도 갱신합니다. 스페인 3부 두 조는 시즌 전환 때 같은 규모로 재편합니다.

**시뮬레이션 경계:** 표에 없는 하위 디비전은 구현하지 않습니다. 따라서 리그 원 아래 리그 투, 프리메라 아래 세군다 페데라시온, 3. 리가 아래 지역리그, 리그3 아래 N2, 세리에 B 아래 C, 리가2 아래 리가3, 브라질 C 아래 D, J3 아래 JFL, K2 아래 K3로의 강등·승격 및 그 경계의 플레이오프는 진행하지 않습니다. 라이선스 심사, 브라질 하부리그의 향후 팀 수 확대, 매년 변경되는 제도는 자동 추적하지 않습니다. 등록된 최하위 리그는 상위 리그로 승격할 수 있습니다. B팀의 승격 제한과 스페인 2부 B팀의 모구단 강등에 따른 동반 강등을 적용하지만, 등록된 최하위 디비전 아래로의 동반 강등은 진행하지 않습니다.

**기존 저장:** 현재 시즌의 경기·일정·계약·능력치를 보존합니다. 현재 일정이 없었던 새 디비전이 필요한 승강 경로와 시즌 후반에 추가된 플레이오프는 다음 시즌부터 적용하고 메시지함에 알립니다. 다음 시즌부터 전체 경로·새 구단 일정이 생성됩니다.

## 경기 기록과 도움

개인 소속팀 경기는 분 단위 조건부 확률과 시드 난수로 상세 시뮬레이션합니다. 기본 능력, 침착성·판단·지능, 피로·압박·멘탈·사기, 해외 적응, 포지션 숙련, 성격·전술·언어 효과를 행동별로 반영합니다. 감독의 포메이션과 역할·압박·전개 속도·창의성·규율 기대가 선발과 실행에 영향을 줍니다.

슈팅·유효슈팅·xG/xA·득점·도움·키패스·패스·경합·수비·선방·실점·거리·카드·출전 시간을 기록합니다. 도움은 다른 선수의 득점으로 연결된 마지막 창출 패스에 기록하며 단순 패스 수만으로 증가하지 않습니다. 도움 이벤트의 선수 ID, 개인 경기 도움, 팀 도움 합계, 커리어 도움 합계가 일치하도록 회귀 검사합니다.

상세 경기는 실제 출전한 선수·교체 시점별로 기록을 발생시키고 경기 중 부상을 가용 인원과 개인 회복 기간에 반영합니다. 최대 5명·3개 교체 시점을 공통 규칙으로 사용합니다. 팬·언론 반응은 실제 경기 사건과 결과에서 생성합니다.

전체 세계의 경기 수가 증가하므로 **개인 소속팀 이외의 경기는 별도 집계 모델**을 사용합니다. 구단 능력·홈 이점과 감독의 경기 전 A·B 플랜 간 전술 상성으로 득점 분포를 계산하고 선발 선수에게 득점·도움·슈팅·패스를 배분하며 골키퍼 선방은 상대 유효슈팅−득점과 맞춥니다. 개인 경기의 상세 전개 모델과 같지 않고 교체·분 단위 이벤트·NPC 경기 부상을 생성하지 않습니다. 생성 선수의 출전·성장·이적·은퇴와 클럽 재정·감독 교체는 계속 처리합니다.

공간 좌표, 실제 전술 전개 전체, VAR·오프사이드, 모든 대회의 세부 징계·등록 규정과 현실 축구 전체를 재현하지 않습니다.

## 이적·계약·세계

자동 영입 제의는 **실제 새 구단 합류일부터 90일** 동안 유예합니다. 예정 이적을 서명한 날과 실제 합류일을 구분합니다. 합류 시 기존 제의·다른 진행 협상·이전 팀에서 시작한 미해결 에이전트 접촉을 정리합니다. 같은 구단 재계약은 유예를 새로 시작하지 않고 자유계약 선수는 적용받지 않습니다. 유예 중에도 플레이어가 직접 요청하는 구단 접촉은 가능합니다.

클럽 접촉은 2–4일, 조건 협상은 1–3일 뒤 회신하며 같은 요청을 중복 제출할 수 없습니다. 이적료·분할 지급·재판매 배분은 두 구단의 AI가 협상합니다. 플레이어는 주급·기간·역할·포지션·보너스·인상·바이아웃·옵션·에이전트 수수료와 합류 시점을 조율합니다. 이적 요청·허가 요청·에이전트 중재도 구단 합의에 영향을 줍니다. 구단·개인 조건·에이전트·메디컬 평가 뒤 최종 서명합니다. 자유계약 선수는 새 계약 전에는 출전하지 않습니다. 임대·노동 허가·실제 재정 규정은 구현하지 않습니다. 개인 상업 계약은 자산·라이프 메뉴에서 별도로 관리합니다.

생성 선수는 고유 ID와 나이·성격·DNA·포텐·출전·부상 이력을 유지합니다. 국가별 한국어 이름 자료를 사용하고 중복을 억제하지만 자료 소진 이후 완전한 무중복은 보장하지 않습니다. 신인·NPC 이적·감독 교체·재정 변화·노화·은퇴·훈련 환경 변화를 처리합니다. 뉴스와 SNS 반응은 게임 사건에서 생성하며 실제 뉴스 수집이나 외부 SNS 게시는 없습니다.

맨체스터 시티는 기존 **사용자 지정 게임 시나리오**의 최하 위상·명성·재정 잠금을 유지하며 유스에도 적용합니다. 현실 구단에 관한 사실 주장이나 평가가 아닙니다. 명문 유스 시작 후보는 모구단의 위상·명성·잠금을 확인합니다.
