# FIRST XI — 축구선수 커리어 시뮬레이터 v12.0

## 개발 지침

**하드코딩 금지.** 게임 수치·요소·선택지·규칙 계수·문구는 단일 `index.html`의 `game-db` JSON에서 관리합니다. 로직은 DB 참조와 계산을 담당합니다. 산술 0/1, 난수·해시 알고리즘, HTML/CSS 구조는 실행 구조입니다.

목표는 데뷔 → 출전 경험 → 주전 확보 → 성장 → 상위 팀 → 연봉·명성입니다. 경기 흐름은 선발 전술판 → 라커룸 → 텍스트 중계 → 상세 결과입니다.

## 실행과 저장

`index.html`을 브라우저에서 열면 실행됩니다. 외부 라이브러리·서버·빌드가 필요 없습니다. IndexedDB 자동 저장, 압축한 로컬 보관본, JSON 내보내기/불러오기를 지원합니다. 자동 저장이 불가능하면 JSON 내보내기를 사용할 수 있습니다. 계정 클라우드 동기화는 없습니다.

저장 스키마는 11입니다. 이전 schema 1–10의 선수·계약·능력치·개인 경기 기록·중계 상태를 보존하면서 새 DB로 확장합니다. 지원 리그의 구단 소속을 새 시즌 명단에 맞추고 미래 일정을 다시 만듭니다. 이미 끝난 경기는 결과·날짜를 유지하며 새 리그 구성과 맞지 않는 경기는 과거 경기로 보관합니다. 지나간 날짜에 새 경기를 추가하지 않습니다. 현재 소속 구단이 지원 명단에서 제외된 경우 `seasonCatalog.clubMigrations`의 대응 구단으로 옮기고 메시지함에 알립니다. 사용자 추가 리그·구단의 ID도 보존합니다.

현재 시즌의 세계 결과는 요약으로 저장하고 개인 경기 보고서는 전체 기록을 유지합니다. 세계 연감은 최근 40시즌, 세계 이벤트는 최근 1,200개, 전체 리그 결과 아카이브는 최근 18시즌을 유지합니다. JSON 불러오기 제한은 128MiB입니다. 잘못된 파일은 검증 후 거부하고 현재 커리어를 변경하지 않습니다. 브라우저 데이터 삭제·저장 제한 설정까지 보존을 보장하지는 않습니다.

## 화면과 중계

프로필·성격 선택 화면에서도 상단 설정 버튼으로 화면 배치, 인터페이스 크기, 금액 단위를 변경할 수 있습니다. 돌아가기·설정 복원 후에도 작성 중인 프로필과 선택 단계를 유지합니다. 인터페이스 크기는 80–200%이며 자동/PC 화면 배치를 지원합니다.

텍스트 중계는 기존 중계창과 버튼을 유지하면서 새 이벤트만 추가합니다. 하단을 보고 있으면 새 내용을 즉시 따라가고, 위로 스크롤해 이전 내용을 읽으면 읽는 위치를 유지합니다. 일시정지·이어보기·경기 종료에서도 중계창과 페이지 스크롤·버튼 포커스를 유지합니다. 종료 시 버튼을 비활성화하여 화면 높이가 갑자기 줄지 않게 합니다.

중계 속도는 0.5배(2초), 1배(1초), 2배(0.5초)입니다. 일시정지 중에도 변경할 수 있고 새로고침 후 선택을 복원합니다. 창이 숨겨지면 중계를 멈춥니다. 경기 준비 때 결과를 한 번 계산하므로 중계 재개·스킵은 기록을 중복 누적하지 않습니다.

## 선수 생성과 DNA

- 프로필, 신체, 주발, 주·부·가능 포지션, 희망 리그·드림클럽을 지정합니다. 이미 다른 칸에서 선택한 포지션은 맞교환합니다. 초기 6능력치 평균은 최대 70이며 420점 예산을 표시합니다.
- 운동 재능·잠재력·축구 지능·야망·프로의식·멘탈·부상 취약성·압박 대처·향수병·언어능력·적응력·침착성·판단력을 설정합니다.
- 성실한 조직형, 자유분방한 스타형, 승부욕 강한 야심가, 차분한 내향형은 각각 다른 성격 효과를 갖습니다.
- 꾸준함·빠른 습득·대기만성·노련함·회복 탄력성의 선천적 특성과 DNA로 성장 경향을 결정합니다. 나이·환경·도약·정체가 실제 경로를 바꿉니다.
- 국내 하부리그 / 유럽 변방 / 명문 유스의 첫 계약 후보를 매번 새로 선정합니다. 희망 리그와 드림클럽은 후보 가중치입니다.

## 훈련과 성장

훈련은 달력에서 실제 경과한 7일마다 누적됩니다. 슈팅 집중 훈련도 다른 능력치와 같은 성장 경로를 사용합니다. 능력치·훈련 누적 증가량을 소수점 두 자리로 표시하므로 정수에 도달하기 전의 성장도 확인할 수 있습니다.

`trainingRules`의 기본 제한은 다음과 같습니다.

| 구분 | 훈련 성장 상한 |
| --- | ---: |
| 집중 훈련, 1주·해당 능력치 | +0.08 |
| 균형 훈련, 1주·능력치별 | +0.018 |
| 시즌·능력치별 누적 | +2.50 |
| 시즌·전체 능력치 증가 합계 | +4.00 |

이는 보장 증가량이 아닌 최대치입니다. 나이·DNA·코칭·훈련 종류·상한 근접도·정체 등에 따라 실제 증가량이 줄어듭니다. 부상 중인 날짜와 회복 훈련은 훈련 성장을 주지 않습니다. 훈련으로 실현 가능한 상한이 현재 능력치 아래로 내려가 건강한 선수의 성장이 영구 정지하지 않도록 연습 여지를 확보하되 타고난 상한을 넘지는 않습니다. 시즌이 바뀌면 훈련 성장 예산을 새로 시작하며 저장/불러오기로 예산을 초기화하지 않습니다.

경기 출전 경험에 의한 성장은 훈련 예산과 별도로 처리합니다. 타고난 능력별 상한과 현재 실현 상한, 출전 경험, 프로의식·야망, 클럽 환경, 사기, 부상 누적, 노화를 반영합니다. 상한 하락만으로 현재 능력치를 바로 깎지는 않습니다. 근육·인대·큰 무릎 부상의 회복 기간과 영구 손실은 다릅니다.

## 지원 리그와 구단

프로필 국적은 기존 8개이며 지원 국내 리그는 10개 국가의 **19개**, 현역 성인 구단은 **380팀**입니다. 각 성인 구단에 유스팀을 하나씩 생성하여 **380개 유스팀·19개 유스 리그**를 제공합니다. 유스는 모구단과 같은 국내 리그에 속한 구단들의 유스끼리 경기합니다. 종전의 여러 국가 유스를 한 리그에 모은 일정은 사용하지 않습니다. 유스팀·유스 대회 구성은 게임용 생성 데이터이며 실제 유소년 대회 참가 명단을 재현하지 않습니다.

## 국내 시즌과 유럽대항전

국내 리그는 같은 리그의 모든 팀과 홈·원정 한 번씩 경기합니다. 20팀 리그는 38경기이며 MLS도 게임에서는 공통 홈·원정 형식의 58경기를 사용합니다. 현실의 컨퍼런스, 스플릿, 플레이오프, 그룹별 특별 규정은 재현하지 않습니다. 모든 리그에 게임용 8월–5월 달력을 사용하므로 한국·일본·미국·브라질의 실제 공식 경기 날짜와는 다릅니다. 국제 휴식 구간과 대륙대회 날짜를 고려하고 같은 구단의 경기 사이에는 최소 3일을 둡니다.

잉글랜드·스페인·독일·프랑스·이탈리아·포르투갈 1부에 별도 유럽대항전을 제공합니다. 최초 시즌은 게임 구단 능력·명성, 이후 시즌은 직전 국내 순위로 참가팀을 결정합니다. 대회별 일정·개인 기록·순위표를 구분합니다.

| 대회 | 참가 기준·규모 | 리그 페이즈 |
| --- | --- | --- |
| 유럽 챔피언스 대회 | 각 지원 1부의 1–4위, 24팀 | 서로 다른 8팀, 홈4·원정4 |
| 유럽 유로파 대회 | 각 1부의 5–6위, 12팀 | 서로 다른 6팀, 홈3·원정3 |
| 유럽 컨퍼런스 대회 | 각 1부의 7–8위, 12팀 | 서로 다른 6팀, 홈3·원정3 |

각 대회 상위 8팀이 단판 8강·4강·결승을 진행합니다. 무승부는 승부차기 승자를 별도로 기록하고 정규시간 득점에 더하지 않습니다. **UEFA 공식 36팀 구조, 플레이오프, 국가별 배정·예선·복잡한 추첨·홈원정 토너먼트를 재현하지 않은 게임용 형식입니다.** 국내 컵과 국가대표 대회는 없습니다.

승강은 K리그1↔K리그2와 J1↔J2에서 시즌당 1팀씩 교환하는 게임용 규칙입니다. EFL 리그 원·프리메라 페데라시온·3. 리가·리그3·세리에 C를 1부와 바로 연결하거나 USL을 MLS로 승격시키지 않습니다. 기타 현실 승강·등록·라이선스 규정은 구현하지 않습니다. 모구단의 승강에 맞춰 유스 리그도 이동합니다.

## 경기 기록과 도움

개인 소속팀 경기는 분 단위 조건부 확률과 시드 난수로 상세 시뮬레이션합니다. 기본 능력, 침착성·판단·지능, 피로·압박·멘탈·사기, 해외 적응, 포지션 숙련, 성격·전술·언어 효과를 행동별로 반영합니다. 감독의 포메이션과 역할·압박·전개 속도·창의성·규율 기대가 선발과 실행에 영향을 줍니다.

슈팅·유효슈팅·xG/xA·득점·도움·키패스·패스·경합·수비·선방·실점·거리·카드·출전 시간을 기록합니다. 도움은 다른 선수의 득점으로 연결된 마지막 창출 패스에 기록하며 단순 패스 수만으로 증가하지 않습니다. 도움 이벤트의 선수 ID, 개인 경기 도움, 팀 도움 합계, 커리어 도움 합계가 일치하도록 회귀 검사합니다.

상세 경기는 실제 출전한 선수·교체 시점별로 기록을 발생시키고 경기 중 부상을 가용 인원과 개인 회복 기간에 반영합니다. 최대 5명·3개 교체 시점을 공통 규칙으로 사용합니다. 팬·언론 반응은 실제 경기 사건과 결과에서 생성합니다.

전체 세계는 시즌당 약 1만 5천 경기로 늘어나므로 **개인 소속팀 이외의 경기는 별도 집계 모델**을 사용합니다. 구단 능력·홈 이점으로 득점 분포를 계산하고 선발 선수에게 득점·도움·슈팅·패스를 배분하며 골키퍼 선방은 상대 유효슈팅−득점과 맞춥니다. 개인 경기의 상세 전개 모델과 같지 않고 교체·분 단위 이벤트·NPC 경기 부상을 생성하지 않습니다. 생성 선수의 출전·성장·이적·은퇴와 클럽 재정·감독 교체는 계속 처리합니다.

공간 좌표, 실제 전술 전개 전체, VAR·오프사이드, 대회별 규정 차이와 현실 축구 전체를 재현하지 않습니다.

## 이적·계약·세계

자동 영입 제의는 **실제 새 구단 합류일부터 90일** 동안 유예합니다. 예정 이적을 서명한 날과 실제 합류일을 구분합니다. 합류 시 기존 제의·다른 진행 협상·이전 팀에서 시작한 미해결 에이전트 접촉을 정리합니다. 같은 구단 재계약은 유예를 새로 시작하지 않고 자유계약 선수는 적용받지 않습니다. 유예 중에도 플레이어가 직접 요청하는 구단 접촉은 가능합니다.

클럽 접촉은 3–6일, 조건 협상은 3–7일 뒤 회신하며 같은 요청을 중복 제출할 수 없습니다. 이적료·분할·재판매 배분, 주급·기간·역할·포지션·보너스·인상·바이아웃·옵션·에이전트 수수료를 협상합니다. 구단·개인 조건·에이전트·메디컬 평가 뒤 최종 서명합니다. 자유계약 선수는 새 계약 전에는 출전하지 않습니다. 임대·노동 허가·실제 재정 규정·스폰서 계약은 없습니다.

생성 선수는 고유 ID와 나이·성격·DNA·포텐·출전·부상 이력을 유지합니다. 국가별 한국어 이름 자료를 사용하고 중복을 억제하지만 자료 소진 이후 완전한 무중복은 보장하지 않습니다. 신인·NPC 이적·감독 교체·재정 변화·노화·은퇴·훈련 환경 변화를 처리합니다. 뉴스와 SNS 반응은 게임 사건에서 생성하며 실제 뉴스 수집이나 외부 SNS 게시는 없습니다.

맨체스터 시티는 기존 **사용자 지정 게임 시나리오**의 최하 위상·명성·재정 잠금을 유지하며 유스에도 적용합니다. 현실 구단에 관한 사실 주장이나 평가가 아닙니다. 명문 유스 시작 후보는 모구단의 위상·명성·잠금을 확인합니다.
